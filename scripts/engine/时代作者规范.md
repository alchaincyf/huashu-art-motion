# 时代作者规范（纯代码绘制）

> 这是艺术史速通复刻那支片子的作者规范：下面的构图坐标、角色设定只适用于这支片子和同类速通/穿越片。通用版见 `references/08-风格作者规范.md`；做新题材要为题材重新构图。

你负责的每个时代 = 一个文件 `scenes/<id>.js`，注册：

```js
SCENES['<id>'] = { draw(c, lt, t) { /* 画满 1920x1080 */ } };
```

- `c`：目标 2D context；`lt`：本段局部时间（秒，从该时代转场开始算，可略大于本段时长）；`t`：全片时间。
- **不要画年份牌**（右上角 1500–1890 × 40–210 由引擎画），这块留背景，别放重要元素。
- **不要改 `lib/`、`engine.js`、`eras.js`、`transitions.js`、别人的 scene 文件**。需要的工具函数写在自己的文件里。

## 可用的库（先读源码）
- `lib/paint.js` → `PAINT`：噪声 noise/fbm、纹理 texture/grain/craquelure、手绘线 roughPath/boilSeed、
  风格渲染器 strokes（流场笔触，支持 palette 区域色板）/dabs/mosaic/halftone/pixelate/facets、`swatch` 色组、`choreo` 共享编舞、steam、particles、`scratch(key)` 离屏画布。
- `lib/rig.js` → `RIG`：`RIG.girl(opt)` 少女骨架（侧身朝左坐，返回各部位 Path2D ＋ 锚点 `G.A`），`RIG.drawGirl(c,G,pal)`（pal.mode 可为 fill/line），
  `RIG.cat(opt)` 橘白猫骨架（朝右坐），`RIG.drawCat(c,K,pal)`，`RIG.drawCup`，`RIG.smooth(points)` 平滑曲线，`RIG.taper` 锥形肢体，`RIG.ik2`。
- **标杆实现：`scenes/09_postimp.js`（梵高）**——看它的结构：平涂底稿 → 风格渲染器重画（区域色板）→ 角色平涂＋细笔触 → 补线稿 → 会动的高光。

## 硬要求
1. **同一个场景骨架**：标准构图——窗(350,120)-(810,560)、猫坐地(390,610)-(690,905)、桌(810,620)-(1200,905)、人(1120,200)-(1500,910)。原片每个时代都对齐这套位置，转场也依赖它。
2. **角色**：人物是 17 岁欧洲金发少女，穿**该时代的少女服装**（服装端庄）；猫是**橘白猫**（头顶/背/尾橘色虎斑，口鼻/胸口/肚子/爪子白色）。
   必须基于 `RIG.girl` / `RIG.cat` 的骨架与编舞（同一副骨架、同一套动作），但画法要换成该时代的画法：可以只取 Path2D 自己填/描/剪影，可以在锚点上加服饰，也可以对骨架点做时代化变形（如埃及的正面眼、黑绘剪影）。
3. **画里的东西要活**：主角动作用 `PAINT.choreo(lt,t)`（端杯 cup、甩尾 tail、眨眼 blink、呼吸 breathe），
   再加 2–4 个**取自该时代视觉母题的小循环**——清单见 `../拆解/分镜表.md` 各时代「镜内动作」（例：岩画动物两张姿态交替奔跑、圣甲虫推太阳球、回纹带滚动、维苏威冒烟、金箔高光扫过、扑翼机飞过、樱花飘落、光斑闪烁…）。
   该时代在片中只停留 0.25–1.4 秒，动作要在这个窗口里**看得出来**。
4. **风格是代码做出来的**：用渲染器/纹理/线条把它画成那个时代的艺术品，而不是剪贴画。线条可用 8–12fps「沸腾」（boilSeed）增加手绘感。
5. **性能**：每帧 ≤ 150ms（1920×1080）。静态部分用 `PAINT.cached` 缓存。所有随机都用种子，同一个 t 必须画出同一帧。

## 自检（每个时代至少 3 轮）
```sh
cd <你的项目目录>   # 里面有 代码工程/（从 scripts/engine 复制）
uv run --with playwright python 代码工程/render.py --solo <id> --stills 0,0.3,0.6,0.9 --out 渲染/<id>
uv run --with playwright python 代码工程/render.py --solo <id> --from 0 --to 1.2 --out 渲染/<id>/clip.mp4
```
把你的帧和原片帧、设定稿并排拼图看（PIL），问自己：①一眼认得出是哪个时代/艺术家吗？②少女像 17 岁金发少女、猫是橘白猫吗？③在 1 秒里看得到画在动吗？④有没有穿帮（错位、断线、遮挡错误、空白）？
有一项不过就改，直到满意。
