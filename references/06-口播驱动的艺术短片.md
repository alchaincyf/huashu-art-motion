# 06 · 口播驱动的艺术短片（方法草案，待第一支实片验证）

**中文** · [English](en/06-voiceover-driven-art-shorts.md)

目标：根据口播表达，使用选定的时代或艺术家画风，制作镜头与画面连贯的动画。最新整片方法见`12-口播整片与经验回流.md`。

> ⚠️ 本页是从艺术史速通的引擎推出来的方案，**还没在真实口播上跑过**。第一支做完把这行删掉，把实测写回来。

## 和速通片的区别

| | 速通片 | 口播短片 |
|---|---|---|
| 时间轴 | BPM 网格 | 口播词级时间戳（来自你的转录工具，如 Whisper 一类的词级时间戳） |
| 风格 | 每段换风格 | **一个风格贯穿**（一位艺术家/一个时代） |
| 镜头 | 固定机位 | 要有镜头语言：推拉、摇移、切景别、跟随 |
| 叙事 | 骨架不变、风格变 | 风格不变、内容随口播变 |

## 流程

1. **口播 → 镜头表**：按句切，每句定「这句话画面上是什么」（具象物/隐喻/人物动作/文字），标镜头类型（全景/近景/特写/推/摇）和时长（来自词级时间戳）。先给花叔看 5–10 行镜头表再动手。
2. **定风格＝定渲染器＋色板＋线条**：从 `风格配方/` 选最接近的一张卡做起点；没有的风格按 04 号第三节新写一个渲染器。先出一帧（三方向硬门：同一句口播的同一帧，三种风格诠释给花叔挑）。
3. **世界而不是画面**：口播片要切镜头，所以把场景建成一个比画面大的「世界画布」（如 5760×3240），各元素有世界坐标；镜头 = 视口（中心、缩放、旋转）。渲染器作用在视口画出来的那一帧上，笔触大小按屏幕像素定，推镜头时笔触不会变粗——这是「画在动」而不是「图片在放大」的关键。
4. **镜头间的流动**：
   - 同场景内：视口插值（推拉摇），配缓入缓出。
   - 换场景：用该风格自己的语言做转场（梵高就是笔触漩涡卷走、浮世绘就是浪、水墨就是晕开）——02 号第 3 层机制。
   - 匹配剪辑：上一镜的形状对下一镜的形状（杯口 → 月亮）。
5. **字与口播**：关键词可以用该风格的字体/笔法写进画里（马赛克字、书法、霓虹），不做通用字幕条；字幕交给剪辑工程另轨。
6. **音乐**：05 号的网格法照用，只是网格让位于口播节奏（句间留白处放转场与音乐重音）。
7. **验收**：和口播并排看，每句话画面是否在讲同一件事；每镜是否在动；风格是否一眼可辨。

## 与视频管线的分工

口播的转录、时间轴、混音、交付走你的视频管线；本 skill 只负责「艺术动画画面」这一轨，产出一条无声 MP4 或 ProRes，给剪辑工程当画面轨。
