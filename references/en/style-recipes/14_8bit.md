# 14_8bit · 1985 8-bit pixel game

[中文](../../风格配方/14_8bit.md) · **English**

## Pipeline
1. **Draw everything on a 240×135 low-resolution canvas** (one low-res pixel = eight screen pixels, matching measured 8px reference blocks), then enlarge 8× with one `drawImage`, `imageSmoothingEnabled=false`.
2. **Per-pixel background `fillRect`** (cache `8b_bg`): cross-dot wall pattern = 6px grid, 3×3 crosses, alternating rows offset 3px; wood floor strips y=106–113, black seam every 24px; bricks 16×6 + 1px gaps, alternating rows offset eight, one cream highlight row (`#fbe2a6`) on top/left edges. Window sky uses three blues (`#0856ef / #47c4f8 / #aae9fb`), boundary bands ±0.05 use `(x+y)%2` checker dithering, the NES way to make gradients.
3. **Characters = RIG paths reduced to low resolution, filled, then spriteize**: separate layer per part (far arm / body and legs / hair / face / bangs / near arm; cat body / cat head), each:
   - `getImageData` → alpha < 110 becomes transparent (remove antialiasing) → quantize the rest to a 14-color character palette (nearest color);
   - 1px black outer contour (a transparent pixel becomes black if one of its four neighbors is opaque).
   **Separate part outlines are essential**: one whole silhouette outline merges hair/face/arms; outlining each part gives NES sprites their inner contours.
4. **All facial features are pixel dots** (eyes 1×2 black + brows; cat eyes 2×2 black + one upper-left white highlight; pink nose 1px; blush 2×1), positioned by rounding RIG anchors `/8`.
5. **Mug does not use RIG.drawCup**: shrinking an AA path to 6px blurs it; directly draw a 6×5 white cup + two red stripes + 3px handle at low resolution, following `G.cup`.
6. **Draw HUD at full resolution**: `PressStart2P` 48px (one font pixel = six screen pixels; 64px is too wide and makes WORLD 1-1 hit the apple icon), 8px black shadow; cat head/heart/apple icons are string bitmaps, each cell 8×8.

## Jeans
RIG.girl wears a long skirt; the 8-bit version uses two `RIG.taper` segments (hip `G.hipSeat`→knee (1222,724)→ankle (1214,872), widths 92/76/56) for blue trousers, far leg darker `#0838a8` and offset back 26px; white sneakers + one red stripe.

## Short loops (only about 0.23s ≈ 11 visible frames; all stepped animation)
- Cat tail: 15fps four-pose loop `[-0.55, 0, 0.55, 0]` (RIG.cat tail parameter), the pixel-animation alternation of a few images.
- HUD heart flash: lt 0.16–0.23 (about frame 630), every two frames: filled heart turns white, hollow heart turns solid red.
- Plant shake: in the same interval, leaves offset whole pixels `[0,1,0,-1]`.
- Question block pops a coin: lt 0.06–0.22, half-sine rises 9px then returns.
- Clouds outside move left 1px every two frames; pixel steam = three columns of 1×2 dots, moving up 1px per 30fps frame on a 6px loop.

## Pitfalls encountered
- RIG cat head reaches y≈535, overlapping the windowsill (window extends to y=590). This shared skeleton position was not moved; 8-bit black outlines emphasize the overlap, but transitions require the standard composition, so it stays.
- `spriteize` reads non-premultiplied RGBA; do not divide by alpha again.
- Performance: warm frames 2.5–6ms, cold start 11ms.
