# 02 · 机制：「艺术史速通」为什么好看

这一页是「速通/穿越」类片子的机制：同一个场景，换一路风格或年代（艺术史速通、一座城市的 100 年、一个人从十八岁到八十岁）。这类题材都能照这五层搭；解说片、故事片、单一风格的短片不照它搭，构图按题材设计。

## 五层机制

**1. 一个固定的场景骨架。** 16 个时代，窗、桌、猫、人、年份牌的位置几乎不动（±40px）。观众的眼睛有锚点，才看得清「变的是风格」。也因为位置固定，转场可以用画内物体当原点（马赛克从猫的位置扩散、光圈从杯子展开）。
→ 做法（速通/穿越类专用）：先定这支片子的构图坐标，所有时代对齐到它。代码里是一份常量，不是每段各画各的。别的题材不沿用这间屋的坐标。

**2. 每个时代是一幅活的画。** 停留 0.25–1.4 秒，但画里一直在动：主角一个连续动作（端杯喝茶）＋ 2–4 个**取自那个时代自己视觉母题**的小循环——岩画动物用「两张姿态交替」跑（这就是岩画多腿表示奔跑的动画化）、埃及圣甲虫推太阳、希腊回纹带滚动、罗马火山冒烟、哥特金箔高光、文艺复兴扑翼机、浮世绘巨浪、梵高星空旋转、包豪斯指针、波普四宫格换色。
→ 做法：每段列「这个时代最有辨识度的 3 个形式元素」，让它们动起来。动作要在停留窗口里看得出来（短段节奏要快）。

**3. 转场 = 下一个时代的签名语言。** 进埃及是石块/挂毯落下、进希腊是陶瓶滚筒转面、进罗马是马赛克砖翻面、进哥特是羊皮纸翻页、进文艺复兴是神光、进浮世绘是神奈川巨浪横扫、进印象派是笔触色点铺满、进梵高是星空漩涡、进新艺术是金边有机形生长、进立体主义是几何碎片、进包豪斯是红黄蓝几何旋转放大、进波普是闪电＋网点、进 8-bit 是像素化、进光追是绿色线框→逐行渲染、进 2026 是三色同心环光圈。
→ 做法：转场不从转场库里挑通用的，从「新风格最有辨识度的形式元素」里长出来。每个转场第一帧加镜头冲击（场景层放大到 1.03，约 20 帧回到 1.0，年份牌不缩放）——拍点上的那一下顿挫感来自它。

**4. 节拍网格加速。** 128 BPM 不变，每段占的八分音符数递减：6 → 4×5 → 3×4 → 2×3 → 1×3 → 结尾放长到 9＋。速度没变，听感和看感越来越急；最后一段放长给笑点留位置。转场时长跟着缩（0.4s → 0.13s），年份滚动也跟着缩（0.55s → 0.07s）。
→ 做法：先列每段想要的时长，四舍五入到八分音符，再整体微调成规律的递减。所有剪点、音乐起音、音效都落在网格上。

**5. 一个连续的叙事锚＋结尾角色梗。** 年份计数器是全片唯一连续的东西：数值只由全局时间决定，转场时新旧两层显示同一个滚动中的数字，各用各的字体（40,000 BC 的岩画手写 → 1350 BC 的芦苇笔 → … → 2026 的几何无衬线）。结尾给角色一个梗（猫三次拍杯把杯子推下桌，少女惊呼，签名写出），用预备、挤压拉伸、跟随、二次动作把它演足——前面 11 秒是「看」，这 4 秒是「笑」，笑点让人转发。

## 补充（2026-10-04 迁移测试 A–D）

- **主角动作跨段连续**：叙事锚不只是计数器，主角的动作也要按全片时间走；每段重做一遍动作，观众看到的是「举杯五次」而不是「同一瞬间换了五种画风」。
- **计数器用年份时段落必须按年代排**；不能重排就把角标换成序号或风格名（引擎角标可插拔）。转场中点硬切新旧角标，避免叠字。
- **第一段没有转场可借时，让画「自己画出来」**（笔触写出、套色一版版落、像素一行行点亮）。
- **签名转场越复杂，时长越长**：原片形状简单所以 0.4s 够；金箔、色带、飘带这类要 0.48–0.5s。

## 换题材时怎么用

| 层 | 本片 | 换成「一座城市的 100 年」可以是 |
|---|---|---|
| 骨架 | 窗/桌/猫/人 | 同一个街角：路灯、店招、行人、天际线 |
| 活的画 | 时代母题小循环 | 每个年代的交通工具驶过、招牌字体闪烁、天上的东西（风筝→飞机→无人机） |
| 转场 | 下一时代的签名语言 | 下一年代的媒介：胶片烧边、电视雪花、像素、扫描线 |
| 节拍 | 128 BPM 递减 | 同 |
| 锚＋梗 | 年份计数器＋猫拍杯 | 年份计数器＋同一只鸽子每个年代都在偷吃东西 |

## 不要学歪的地方

- 不要把「16 个时代」当配额。速通/穿越类的机制是「风格在变、骨架不变」，3 个时代也成立；它不是所有题材的机制。
- 不要逐像素复刻原片。复刻是学机制的手段，交付物是你理解后的版本（花叔选了金发少女＋橘白猫，就是在原片骨架上换角色）。
