# 10_nouveau · 1896 新艺术运动（慕夏海报）

**中文** · [English](../en/style-recipes/10_nouveau.md)

文件：`scenes/10_nouveau.js`（约 300 行）。性能：warm 平均 29ms、最大 37ms，首帧（建缓存）≈80ms；确定性通过（同一 lt 两次逐像素相同）；lt 0.35→0.65 运动差分 13.1% 像素。片中停留 0.70s（T09 有机波浪转场 0.24s，从 (1330,320) = 少女光环长出来）。

## 管线
1. **底版全缓存 `nv_bg`**：灰绿→米绿→桃色三段竖渐变（`#b9cba0`→`#cfd3a6`→`#ecc9a2`，只铺内框 34..1886×32..907）；圆点花纹 = 环 r10 + 心点 r2.6，行距 54、列距 62，奇数行错 31（菱形交错），色 `rgba(120,140,100,.38)`；240×135 的 fbm 小图放大 α0.5 叠石版斑驳（比全屏算噪声快几百倍）；马赛克地砖带 20×24 一格、9 色循环 `(k*7+(k>>2))%9` 打散；绿横幅 `#8fac80`；标题 `Marcellus-400` 76px、letterSpacing 12、先 7px 深棕描边再填奶白；金框 = 外 6px 金 `#c9a24a` + 内外两条 2px 深棕。
2. **可变线宽路径 `ribbon(pts, w(q))`**：点列先 Catmull-Rom 加密（每段 4–10 点），每点沿法线两侧各偏 w/2，拼成闭合多边形 fill。所有「鞭线」都是它：茎、叶、铁艺桌腿、横幅卷草、头发、热气。`swellW(wmax)` = 两头尖中间粗（sin 包络），这就是慕夏线条的粗细呼吸。螺旋收尾 `spiral(cx,cy,r0,a0,turns,dir)`：半径线性收到 15%。
3. **慕夏式「外轮廓粗、内线细」——整体剪影错位法**：角色（猫＋少女＋头发＋披帛）全部画进离屏层 L（RIG 的 both 模式，lw 2 → 内线按部件顺序遮挡正确）；再复制 L 用 `source-in` 染成深棕 `#4e3320`，在主画布按 (-1.5,-1.5)、(3.5,4.5)、(2,2.5) 三个偏移垫在 L 下面。结果：剪影外缘一圈 1.5px，右下侧 4–5px 厚边；内部线保持 2px。只多 3 次全屏 drawImage。
4. 颗粒 `P.grain('nv', .05, 暖棕, .14)` 盖最上层，像石版印刷。

## 母题动画（0.7s 内都要看得见）
- **太阳升起**：按原片测量（509 帧 (583,400) → 530 帧 (576,299)，≈-5px/帧）写成 `sy = 400 - (lt-0.267)·288`、`sx = 583 - (lt-0.267)·20`，lt=0 时在 477（藏在山后），lt=0.7 到 275。山丘色带画在太阳之后 = 天然遮挡「从山后升起」。
- **铅条光芒转动**：14 根放射铅条从日心 r92→r420，角度 `+lt·0.9·0.25` 慢转并带 ±0.04 摆动；铅条随太阳移动，所以整窗玻璃分割都在变——这是窗里最显眼的动。
- **彩色玻璃边带**：沿拱形内缘（直边+椭圆弧 rx219 ry130）每 17px 放一块 14×14 色片，按切线旋转，6 色循环。
- **罂粟/百合摇摆**：花头水平位移 `sin(7.5t+φ)·13 + sin(3.1t+2φ)·5`，茎是 ribbon 的三控制点曲线只推上段；左右两丛相位相反；叶片 0.3 倍幅度。
- **光环转动**：少女光环 R172，18 颗圆钉 `+0.9t` 转，内圈 32 片玫瑰窗花瓣 `-0.63t` 反转；猫光环 R106 八瓣橙花 `-1.1t` + 金色虚线环 lineDashOffset 走。
- **头发**：先一大块发团（16 点 smooth，外缘按 `sin(6t+y·0.035)·9` 波动），再 7 绺背后卷发 + 2 绺肩前卷发：每绺 12 点 S 曲线 `sin(7.4q+φ-7t)·(6+20q)`（行波往下传）、末端接 1.2 圈螺旋、宽 14–18 → 2.5 递减，奶黄高光芯 + 深金细线。头顶外缘 6 个小卷做体积。所有点跟随 `G.A.headC` 的偏移（喝水仰头时一起动，越往下跟得越少）。
- **S 形装饰热气**：3 条奶白 ribbon（宽 26/20/14）+ 1.8px 棕描边 + 中线，`sin(4q+φ-6t)·(18+70q)` 行波，横向间距随高度 ×(1+2.6q) 散开，末端 34px 螺旋；整体 `lean = -90 - 160·cup` 往左倒——**踩坑**：choreo 把杯子举到嘴边，热气如果竖直升会横穿少女的脸，必须随 cup 往窗那边倒。
- choreo：端杯、仰头、眨眼、甩尾、呼吸全用 RIG；碟子留在桌上（杯子被端走后桌面不空）。

## 踩坑
- **`drawGirl(mode:'line')` 叠在最上层会把被遮住的部件轮廓（远侧袖子）画穿躯干**（09 标杆也有）。改成在离屏层里用 both 模式按部件顺序画线，再整体做粗外轮廓。
- 头发最初是 7 条 34px 宽的长带，像香肠/面条；慕夏头发 = 一块发团打底 + 细绺 S 卷 + 螺旋收尾，宽度 ≤18。
- 自检差分别拿 lt<0.33 的帧：引擎在转场开始后 20 帧内有 1.03 倍「拍点冲击」缩放，差分会全屏发红。

## 仍可改进
- 猫仍是 RIG 的坐姿（白色直腿），设定稿是趴卧的毛茸茸橘猫；慕夏味主要靠光环和粗细线撑。
- 标题用 Marcellus，设定稿是更圆的手绘新艺术字形；可以手写一套字母路径。
