# 音轨方法 · 速通片的代码合成配乐（拆解方法＋原创示例）

**中文** · [English](../en/style-recipes/_score-art-history-speedrun.md)

这一页是从一次拆解里沉淀的方法：参考片是 X 用户 Tak（@cherry_mx_reds）的 15 秒《Art History Speedrun》，它的配乐本身就是代码合成的。这里只保留**怎么拆、怎么写、怎么混**，不保留对原曲的逐音转录。

配套脚本：`scripts/audio/synth_艺术史速通.py`。乐谱是一段**原创示例**（D 小调，和声 Dm–B♭–F–C），段落结构和画面的 `scripts/engine/eras.js` 一致，乐器库和混音链可以直接复用，换成你自己的乐谱即可。

---

## 0. 一句话结论

速通类短片的配乐可以是**一张严格的 BPM 网格上的程序化编曲**：17 个时代按「八分音符个数」排布（6,4,4,4,4,4,3,3,3,3,2,2,2,1,1,1,9），越往后每段越短，靠「段落变短」制造加速感，速度本身不变。每段换一套该时代的代表乐器，一个三音动机随和弦移调贯穿全片。音乐在网格上停住后，接一串卡通音效（叮、滑哨坠落、碎裂、猫叫、收尾拨弦）完成结尾笑点。

## 1. 怎么拆一条参考配乐

| 量什么 | 方法 | 精度/可信度 |
|---|---|---|
| 拍速与网格 | 对 STFT 做 superflux 式频谱通量（hop 2.5ms），取峰值作起音，再用最小二乘拟合 `t = t0 + n·E`（共 28 个起音） | E = 0.23431s（八分音符）→ **128.04 BPM**，网格零点 t0 = 0.028s。残差全部在 ±4ms 内，人手演奏做不到，可以断定是代码排程 |
| 时代边界 | 三路互证：①网格位置；②MFCC 新奇度曲线（前后各 0.2s 均值的距离）的峰值；③视频逐帧差分的峰值 | 音频边界（网格）与 MFCC 峰值的偏差 ≤20ms。画面转场比音频晚 0–0.2s（画面用 0.1–0.2s 的擦除/变形转场） |
| 音高 | ①Spotify basic-pitch 复音转录（ONNX，Python 3.11 临时环境）；②在 16 分音符网格上取 85ms FFT 峰值，起音前后增益 >6dB 判为新音；③自写 CQT 半音能量图人工核读 | 旋律主音的可信度高（两种方法一致）。和声内声部、浮世绘和梵高两段的细节可信度中等 |
| 音色 | 对每个旋律音取起音后 20–220ms 的谐波幅度（H1–H8，±1.5% 窄带），再测窄带包络的起音时间和衰减（+50/100/200ms 相对峰值） | 复音会混进别的声部，谐波比只能当倾向看 |
| 打击乐 | 逐 16 分音符测 >6kHz（噪声类）和 <150Hz（鼓类）的能量跳变 | 高 |
| 音效 | 对 13–15s 用 20ms 步长的 FFT 峰值追踪频率轨迹，配合 2.1s 的画面接触表（每 0.1s 一帧）对齐事件 | 高 |
| 响度 | ffmpeg ebur128；分段用 BS.1770 K 加权、不加门限的均方 | 整体 **-14.3 LUFS，LRA 0.9 LU，真峰 -2.4 dBTP**（常听到的「平均 -16.6dB」是 RMS 均值，口径不同） |
| 全模态模型「听」 | 用一个全模态模型整片听一遍，按作曲家视角自定义提问 | 只当候选，逐条回校，见第 4 节 |

---


另外两条经验：音色判断看「起音后 20–220ms 的谐波幅度＋窄带包络衰减」最稳；判断「是不是代码合成」看三件事——时间残差是否在 ±5ms 内、音色是否都是正弦/方波/锯齿/指数衰减这类教科书构件、静处有没有录音底噪。

## 3. 结尾音效（按「停—悬—砸—反应—收」）

| 事件 | 合成方法（脚本里的函数） |
|---|---|
| 音乐停 | 低音约 150ms 快速衰减，不硬切 |
| 爪子碰杯「叮」 | 几个 5–7kHz 的非谐波振铃＋一点 1.5kHz（`tink`），同时一道高频嗖声（`swipe`） |
| 杯子坠落 | 纯正弦指数下滑约 1550→325Hz、0.35s（`slide_whistle`） |
| 落地碎裂 | 80Hz 左右闷击＋宽带噪声（质心 5–7kHz、约 0.45s 衰减）＋陶瓷非谐泛音＋几颗碎片小碰撞（`crash`） |
| 猫叫 | 线性折线音高（上行再下行）的谐波合成＋两个共振峰，整段最响（`meow`） |
| 签名出现 | 两下 ~90Hz 轻「啵」叠一点亮点（`end_thump`） |
| 收尾 | 落在主音的低音拨弦 |

时间点全部从画面接触表（每 0.1s 一帧）对齐到画面事件。

## 4. 混音做法（脚本后半段，原样可用）

1. 0.5s 小空间混响，12ms 预延迟，湿声 9%
2. 逐段低频暖底：按段的和弦根音（`BED_ROOT`）铺「三角波＋下八度正弦，250Hz 低通」，电平按「地板比段响度」的相对值自动算，已经够的段不加
3. 逐段 2–6kHz 动态 EQ（`MID_ORIG`）
4. 逐段补 >6kHz 的空气噪声（`HF_ORIG`）
5. 逐段 K 加权响度对齐 `target`，迭代 4 次，10ms 平滑增益防拉链声
6. 可选：15.8kHz 陡峭低通，模拟流媒体 AAC
7. 整体对齐 LUFS，再做前视峰值限幅

有参考片时，`target / MID_ORIG / HF_ORIG / LOW_FLOOR_ORIG` 填参考片逐段量出来的值（用第 1 节的方法）；没有参考片时，示例里的「统一相对值」就够用。

起音软化的经验：拨弦模型 2ms 硬起音听起来太「点」，改成 10ms 线性起音、高次谐波起音更晚（每升一次谐波 ×1.6，上限 35ms）、起音噪声减半并加 7kHz 低通，整体会连贯很多。

示例的产出：48k 立体声，15.06s，-14.0 LUFS，真峰 -1.5 dBTP。

```
uv run --with numpy --with scipy --with soundfile python scripts/audio/synth_艺术史速通.py
```

## 5. 可复用规律：给任何动画做代码合成配乐

下面这些可以直接照抄。

1. **先定一张 BPM 网格，所有东西都对齐到它上面**。128 BPM（八分音符 0.234s）适合「速通、蒙太奇」这类节奏；剪辑点、音乐起音、音效落点全部取 `t0 + n·E`。好处是画面怎么剪，音乐都不会显得乱。参考片的时间残差只有 ±4ms，这种「机器般的准」本身就是风格的一部分。
2. **用「每段八分音符数递减」做加速，不要提速**。本片是 6 → 4×5 → 3×4 → 2×3 → 1×3，到最后一段再放长（9）让观众喘口气、给笑点留位置。速度不变，听感却越来越急；而且每段都落在网格上，和画面切点天然同步。做法：先列出画面每段的时长，四舍五入到八分音符，再整体微调，让递减变得规律。
3. **一个三音动机，换乐器、随和弦移调重复**。选一个短小、节奏鲜明的细胞（示例乐谱是 ♪♪♩「级进上行、再下跳」），每个场景用该时代或风格的代表乐器演奏一遍，音高跟着当段和弦走。和声骨架用一个四和弦循环（示例是 Dm–B♭–F–C）就够；想做「出格感」的段（异国、前卫）只换调式或加三全音，节奏和网格不动。开场可以用动机的倒影或扩大版（示例洞穴段是下行的附点四分）先立住。
4. **段间不做交叉淡化**。新段在网格上硬起音，上一段的音符保留自己的自然尾音（拨弦 30–300ms，持续音约 150ms 的 release），可以让一个低音持续音跨段延续来「缝」两段。这样每次换场都有清楚的「咔」，又不会断。不需要每段都加转场嗖声（参考片一个都没有）。
5. **结尾音效按「停—悬—砸—反应—收」设计**：
   - 停：音乐在网格上停住，用约 150ms 的快速衰减，不要硬切
   - 悬：一个小「叮」作为引子，接下滑哨（纯正弦指数扫频，约 0.35s、2 个八度多）
   - 砸：闷击 + 宽带噪声 + 非谐泛音 + 几颗碎片小碰撞，约 0.45s 衰减完
   - 反应：角色发声，比如线性折线音高的「喵」，放在砸之后约 0.5s，整段最响
   - 收：一两下轻「啵」配签名，最后一个落在主音或属音上的低音拨弦
   全部按事件时间点从画面接触表（每 0.1s 一帧）对齐。
6. **响度对齐方法**：
   1. 先量参考片的整体值（ffmpeg ebur128：积分 LUFS、LRA、真峰）
   2. 再按段量 K 加权响度，以及 2–6kHz、>6kHz、40–220Hz 地板相对段响度的差值
   3. 合成后依次做：逐段低频暖底 → 逐段中高频动态 EQ → 逐段空气噪声 → 逐段响度迭代对齐（3–4 次，10ms 平滑增益，防止拉链声）
   4. 如果参考是 AAC，再加 16kHz 低通
   5. 最后整体对齐 LUFS，并做前视峰值限幅
   全程用「相对段响度」的差值，不用绝对值，这样换素材、换整体响度都不用重标。
7. **synth.py 改成通用模板的方式**（结构不动，只换四块数据）：
   - `T0, E`：网格零点与八分音符时长（BPM → `E = 60 / BPM / 2`）
   - `edges / target / MID_ORIG / HF_ORIG / LOW_FLOOR_ORIG / BED_ROOT`：段落边界和逐段参考值；没有参考片时，`target` 统一填一个值即可（比如 -14），其余三项填「不补」
   - `era(n0, items)` 的乐谱块：每段一行列表，元素是 `(相对八分位置, 乐器函数, 增益, 声像)`。乐器函数库（`pluck` 拨弦族、`additive` 持续音族、`kick / clap / hat / taiko` 鼓族、`chip / supersaw` 合成器族）可以直接复用，新风格一般只要调 `pluck` 的谐波表和衰减参数
   - 音效块：按事件时间调用 `tink / slide_whistle / crash / meow / end_thump`，参数（频率、时长）从参考片测得，或按第 5 条的模板自己定
   后半段混音链（暖底 → EQ → 空气 → 响度迭代 → 低通 → 限幅）原样保留。
8. **分析流程的顺序**：
   1. 起音通量拟合网格，先拿到 BPM 和 t0
   2. 在 16 分音符网格上逐格做 FFT 新音检测，再用 basic-pitch 复音转录交叉验证
   3. 用窄带谐波比和包络判断音色
   4. 用高频、低频能量跳变判断打击乐
   5. 全模态模型只当候选，逐条回校。实测它在乐器判断上可靠，在拍速（说 120，实测 128）、动机音数、「转场嗖声」、音效时间上都错了
