# 11_cubism · 1912 分析立体主义（毕加索／布拉克）

**中文** · [English](../en/style-recipes/11_cubism.md)

文件：`scenes/11_cubism.js`（约 280 行）。性能：warm 平均 13ms、最大 19ms，首帧（建缓存）≈100ms；确定性通过；lt 0.34→0.46 运动差分 6.9% 像素。片中停留 0.47s（T10 碎片转场 0.24s）。

## 管线
1. **底版全缓存 `cb_bg`——「透明叠面」**：核心函数 `plane(g, pts, col, alpha, r)`：每块面一条线性渐变，起点取第 0 顶点、终点随机取另一顶点，三个色标 = 混 25% 米白 → 原色 → 混 40% 深棕，alpha 0.18–0.7。叠法：18 块手排大面（照原片构图位置）+ 桌下 9 片放射扇面（自 (1000,1090) 发出，亮暗交替 α0.3）+ 70 片随机 3/4 边形（避开右上年份区）。多层半透明渐变叠起来就出现分析立体主义那种「透明、互相穿插、每面一亮一暗」的空间。
   - 肌理面：4 块点画（9px 菱形格 r1.6）、4 块排线（7px 间距斜线）、左缘一页横线纸。
   - 布拉克短划砂纹：9000 个 3–8×1.5px 小划，55% 米白 α0.28 / 45% 深棕 α0.16——原片那种「砖纹」质感就靠它。
   - 46 条贯穿细直线（1.3px α0.55）= passage。
   - 仿木纹 `wood()`：沿长边画 S/6 条波浪线，过节疤位置加高斯鼓包 `14·exp(-(u-k)²/0.01)`，节疤 4 圈椭圆。用于桌面和右侧木板（布拉克的梳纹假木）。藤编椅背 = 10px 菱形孔点 + 双向斜线。
2. **窗格碎面滑动**：窗景单独缓存成 560×540 大图（55 片蓝灰切面 + 3 条斜光束 + 埃菲尔铁塔 + 海鸥弧），四格各自 clip 后以不同偏移取景 `dx = sin(9lt+1.7i)·18 + 10fps 抖动 ±3`、`dy = cos(7lt+i)·8`——同一窗景在四格里错位 = 多视角拼合；每格另有一片半透明三角以 260px/s 横向滑过。
3. **CAFÉ 模版字跳动换位**：`AlfaSlabOne-400` 104px 画进离屏小层，12fps 卡点（`st=floor(lt·12)`），顺序表 `CAFÉ/ACFÉ/CAÉF/CFAÉ` 轮换，每步每字 y ±13、旋转 ±0.11rad（hash 取）；然后 `destination-out` 切出横竖断口 = 模版字（断口透出底下的叠面，比画纸色条真实）。
4. **报纸 JOU**：缓存 300×190 小图（LibreBaskerville-700 84px「JOU」+ 12px 标题「LA BATAILLE / S'EST ENGAGÉ UN CHAT」+ 三栏灰色假字），每帧以 8fps 微颤（旋转 ±0.0125rad、x ±1.5px），右上折角按 `sin(20lt)` 翻。
5. **角色 = 自写切面器 `facetize`**：RIG 平涂（fill 模式，无线）进离屏层 → 读回该包围盒像素 → 抖动三角网（每格随机选对角线）→ 每个三角在质心取色，`×(0.8+0.38·rand)` 明暗、再做一条从顶点 0 到顶点 2 的亮→暗渐变 → **三角不裁剪**直接画回去（质心 alpha<120 的跳过）。不裁剪是关键：剪影边缘被切成锯齿直边，有的三角还伸出轮廓外——就是立体派「平面溢出轮廓」的感觉。
   - 少女 cell 58（大面），发区再用 cell 26 细切一遍、只切「像金发的颜色」（`only: R>150 && B<130 && R-B>60`），猫 cell 26。
   - 顶点每 8fps 抖 ±8% cell、16–35% 的三角明暗跳 ±12%（boil）→ 角色在「微动」，原片 548–562 帧猫区域就是这样。
6. **切完再补毕加索式的结构**：脸重铺两块肤色明暗面（切面会把金发色带进脸）+ 前半张脸蓝灰面 α0.82 + 正面杏眼（侧脸上画正面眼）+ 螺旋耳 + 红唇；白领两块明暗三角 + 三颗扣；裙摆从腰部 8 条放射切线 + 亮暗交替楔面；外轮廓用直线段 `segs()`，每段两端各外伸 10–16px（线画出界）。猫：六边形直线头轮廓、`bodyPts` 直线身轮廓、黄色菱形眼 + 竖瞳、侧面三角鼻。
7. 最上层 5 片 α0.2 的叠面压在人和猫身上并以 `sin(6lt)·8` 错动——把角色「嵌」进空间，不像贴在背景上。

## 踩坑（重要）
- **不确定性：第一帧和之后不一样。** 两个原因叠加，都只在第一帧出现：① 要 `getImageData` 的离屏层第一次画时走 GPU，读回后 Chrome 把它转成 CPU 光栅，抗锯齿不同 → 质心取色不同 → 三角颜色不同；② 更主要的：离屏层的 context 状态（facetize 里设的 `lineJoin='round'`、segs 的 `lineCap='round'`）会残留到下一帧，第一帧用的是默认 miter/butt。修法：自建层 `getContext('2d',{willReadFrequently:true})`，**每帧开头用 `g.reset()`（清像素 + 清状态）而不是 `clearRect`**。用 hash 对比「同一 lt 连渲三次」才查出来。
- 切面 cell 34 时满身小三角，像 low-poly 3D 模型而不是立体派；58 才有「大块明暗面」。
- 第二遍发区细切一开始用圆形 clip，把半张脸也切成了金色——加了按颜色过滤的 `only`。

## 仍可改进
- 少女整体轮廓仍是 RIG 的写实曲线，切面只改了边缘；更彻底的做法是把肩、肘、膝都换成折线骨架再切。
- 原片色调更暗、明暗对比更强（大块深褐面更多），我这版偏亮。
