# 12_bauhaus · 1923 包豪斯海报

**中文** · [English](../en/style-recipes/12_bauhaus.md)

文件：`scenes/12_bauhaus.js`（约 210 行）。性能：warm 平均 5ms、最大 9.5ms，首帧≈85ms；确定性通过；lt 0.34→0.46 运动差分 4.9% 像素（黑杆、格窗、同心弧、猫、球、人偶都在动）。片中停留 0.47s（T11 蓝方块/红圆/黄三角/圆孔转场 0.20s，原点 (1330,590) ≈ 红圆圆心）。

## 管线
1. **底版全缓存 `bh_bg`**：米白旧纸 `#ebe3cf` + 320×180 fbm 小图放大 α0.5（做旧斑驳）+ 贯穿细斜线 (40,170)→(1900,840)（压在窗后）+ 左上黑横条 (60,61,256,13)、红竖条 (292,105,24,468) + 竖排 bauhaus（`Poppins-800` 210px，`rotate(-π/2)` 后水平缩放到正好 820px 长，原点 (262,1000) 自下而上读）+ 灰小方块 + 地线 (345,898)-(1860,915) + 黄直角三角 + katze（Poppins-800 150px，红 `#d3262b`）+ 右下两行 Poppins-600 31px + 黑面桌/镀铬管腿（三色线性渐变）+ 布劳耶悬臂椅（同一路径描 15px 深灰 / 10px 镀铬 / 3px 高光偏移 2px）+ 两层颗粒（暗点 0.02 密度 α0.35，旧印刷黑斑）。
2. 红圆单独缓存 520²：底色 + `source-atop` 叠 fbm 浅色斑 α0.55，模仿丝网/石版的不匀墨。
3. 角色、构成全是几何体：没有任何曲线描边，只有圆、方、三角、粗杆。

## 母题动画
- **斜长黑杆像指针转**：按原片逐帧量的角度（575–579 帧 28°，581 帧 33°，583 帧 37°，585 帧 42°，587 帧 46°，591 帧 49.5°）写成 `deg = 28 + 21.5·easeOut(clamp((lt-0.26)/0.22))`。转轴 = 毂心 (1125,195)（原片对比 576/590 帧确认：毂不动、下端扫下来），杆 27px 从 -432 到 +150，细平行线偏 30px，红短杆偏 -30px，毂内弧跟着转。
- **蒙德里安格窗轮换**：4×4 格（内框 366..794 × 126..561，格 100×101、缝 9.5），6 个格子参与轮换，13fps 卡点 `step=floor(lt·13)`，每格相位不同、`(step+2·sw)%9 < 6` 才换（不是每拍都换，节奏不机械）；轮换色只用红黄蓝米浅蓝灰。图样格（9px 方格纸）、四分之一圆格保留。
- **同心弧**：红圆右侧 6 条弧，起点相位 `sin(9lt-0.7i)·0.05` 波动、半径 `±3` 呼吸、弧长在 0.4s 内从 55% 扫到 100%——像声波往外推。
- **杯上热气**：一根 2.2px 正弦细线（26 个周期/170px、`-18t` 行波），线性渐变淡出。
- **猫拨球滚一下**：右前爪 `tap = sin(clamp((lt-0.05)/0.16)·π)` 往前伸 36px 再收；蓝球 r31 在 `lt 0.13→0.47` 以 easeOut 从 x712 滚到 816，**转角 = 位移/半径**（白直径线＋白点看得出在滚），滚动中身后两条速度线。尾巴 = 26px 粗橙弧 + 同宽虚线深橙条纹，角度跟 `choreo.tail·0.5`。

## 角色的几何化（锚点全来自 RIG）
- **施莱默人偶**：头 = 圆 r70（`G.A.headC + (14,-18)`），金色几何发片 = 后半个头的扇形（-1.95→1.15rad）+ 额前三角 + 发髻圆 r34 + 背后半圆发片（`G.A.back`）；脸 = 黑竖条眼（眨眼变横条）、红方腮、短黑口。头部整组绕 `G.A.neck` 按 `G.tilt` 转（喝时仰头）。躯干 = 蓝梯形 + 后半黑梯形（随 breathe 起伏）；裙 = 黑扇面 r178 + 蓝梯形；四肢 = 粗黑圆头杆，关节 = 米白圆盘 + 5px 黑圈 + 黑心点。近侧手臂直接用 `G.A.shoulder/elbow/hand`（RIG 的 IK 端杯），远侧手臂平放桌上（复现原片那只伸向桌面的手）。
- **猫**：身体圆 r100（`K.box` 推算的 (536,805)，随 breathe 缩放）+ 左侧 4 条深橙横条（clip 在圆里）+ 右下米白扇面（橙白块面）；头 = 104 方块（`K.headC + (14,48)`，随尾巴相位微转 ±0.08rad）+ 黄三角耳 + 米白下半脸 + 深橙额带；眼 = 白圆 + 黑竖条瞳。

## 踩坑
