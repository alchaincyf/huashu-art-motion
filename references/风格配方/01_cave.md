# 01_cave · 40,000 BC 洞穴岩画（纯代码）

**中文** · [English](../en/style-recipes/01_cave.md)

文件：`scenes/01_cave.js`（约 330 行）。最终性能：warm max 22ms / mean 21.1ms，cold（建缓存）在引擎 boot 时完成；确定性通过；0.2↔0.7s 运动差分 3.9% 像素。

## 管线
1. **岩壁（全部缓存，`cave_relief`/`cave_bg`）**
   - 半分辨率 960×540 算高度场：`fbm(x·0.0022,4oct)·1.0 + fbm(x·0.011,3oct)·0.16 + noise(x·0.05)·0.03`（坐标用全分辨率像素）。
   - 有限差分×52 得法线，光源 L=(-0.55,-0.62,0.56)（左上），`shade = clamp(0.5+(dot-0.56)·0.9)`；底色在 `#ce925a`(亮赭)/`#6e4426`(暗)/`#b6643a`(红斑) 之间用两层低频 fbm 混，再 ×(0.72+shade·0.55)。放大到全屏用平滑插值 → 起伏柔和。
   - 叠两层 `P.grain`（暗 0.22 密度 α0.32、亮 0.10 α0.28）出颗粒；10 条随机游走裂缝（每步转角 ±0.45rad、步长 14–40px、12% 概率分叉），深线下面垫一条 +1.6px 偏移的亮线 → 刻痕感。
   - 暗角：径向渐变 r 260→1180，外圈 α0.8；中心静态暖光用 lighter（α0.36）只照亮岩壁。
   - **踩坑：relief 的中频项系数一大（0.35、×60 法线）整面墙就成了迷彩/沙丘，人物叠上贴图后像迷彩服**。中频降到 0.16、法线 ×52 后才像岩面。
2. **「颜料吃进岩石」**
   - 所有图形统一画法 `shape()`：先用 **fuzz 图案**（稀疏炭点，宽 2lw+7）描一遍 → 再用 **ink 图案**（炭黑、7% 随机孔洞 + 噪声 >0.58 处大孔，宽 2lw）描 → 最后平涂填色盖住内半圈。效果 = 实心炭线 + 喷点毛边，且 painter 顺序天然处理遮挡（手臂盖住外衣的线）。
   - 炭笔「沸腾」：两张 256 图案每 1/9 s 用 `pattern.setTransform` 随机平移一次，几何不动、颗粒在跳，比抖动路径省且不变形。
   - 整个颜料层画完后 `source-atop` 叠一张 `cave_figtex`：岩面阴影→黑 α(0.5-v)·150、亮处→暖白 α(v-0.5)·50、暗/亮颗粒、低频干湿斑 α≤70。**颜料层只有一次全屏合成**，所以 19ms。
   - 填色都是不透明平涂，颜色靠贴图「脏」掉；不要用 multiply 叠颜料——白垩（猫的白）会消失。
3. **负形手印/爪印**：320² 临时画布高斯喷点（σ46·s 3200 点 α0.15–0.6 + σ28 1400 点），再 `destination-out` 一张实心手形蒙版，最后蒙版 α0.3 填 `#f6e2bc`。**手形必须逐块 fill 到蒙版**：把手掌椭圆和手指胶囊 addPath 进一个 Path2D 一次 fill，子路径绕向相反处 nonzero 抵消，出现缺口（r4 踩到）。
4. **火光**：每帧一层径向渐变，中心 (1000+40·noise(t·3.1), 540+26·noise(t·2.3))，强度 `0.13+0.09·noise(t·8.5)+0.04·sin(21t)`，**用 overlay 合成**（α=强度×2.6）。外圈再叠一层随火光反向呼吸的暗角。踩坑：一开始用 lighter，少女的金发和兽皮被洗成粉白、失去赭石饱和度，改 overlay 后颜色回来了。
5. **余烬**：`P.particles` 三组（左 0–360 ×11、右 1540–1920 ×12、中间 ×5），y 从 1110 漂到 120，life 5.5s；亮核 r 2.2–4.6 + 3.2 倍光晕，`|sin(6t+1.9i)|` 闪烁，`sin(q·π)` 首尾淡入淡出，lighter 合成。

## 母题动画
- **野牛/马两张姿态**：`ph = floor(t·60/7)%2`（每 7 帧换），腿的终点两套坐标（伸展/收拢）、头绕颈点 ±0.07rad、整体 y 交替 -3/+1px；马与野牛反相。腿只用炭线（原片也是），身体是填色剪影 + 背脊一道 22px 深色晕染（拉斯科式明暗）。
- **端杯**：没用 RIG 的杯子轨迹（桌面→嘴，桌面点在少女胸前，不像原片「伸臂端在半空」）。自定：`hold=(1084,506)` → `mouth=HP(1224,380)`，进度 `k = choreo(max(0,lt-0.95)).cup`（choreo 曲线整体平移 0.95s，对上原片 58 帧起举杯），手臂用 `RIG.ik2(G.A.shoulder, cup+(34,10), 170,128,-1)`；`RIG.girl({cup:k})` 仍负责头部后仰与喝的微仰。k 在 lt≈1.85（T01 转场末）到 1。
- **热气**：三条炭线 `x0 + sin(13q − 11t + 1.3j)·6`，高 58px，跟杯走。
- **猫**：RIG.cat 的 head/eyes/nose/earInner/stripes/tailPts 锚点 + 自画梨形身体、白胸、白前腿、大腿弧线；尾巴 = fuzz/ink/橙三层描边 + 每 4 个采样点一道横纹；眨眼来自 choreo.blink。
- **猫的尺寸（复核返修）**：RIG.cat 原尺寸耳尖在 y≈535，顶进壁画框底边(550)。整只猫用画布变换以脚底 (540,905) 为锚缩 0.86（translate→scale→translate，RIG.cat 本身仍 s=1），耳尖落到 y≈582，与框底留出约 30px，脚底不动。线宽随之 ×0.86，看不出差别。
- **标题**：`Kalam-700` 78px letterSpacing 7，水平缩放到 930px 宽，`#9b2a18`，画进颜料层（同样吃岩面贴图）。α = t<0.933 ? 1 : 1-(t-0.933)/0.2。

## 运动量返修（复核口径：静止段帧 21–84，480×270 逐帧平均帧差）
复刻 0.62 vs 原片 0.86，偏静。只加局部动作，不靠全屏闪烁：
- 火光：强度 `0.14+0.11·noise(9.5t)+0.04·sin23t+0.03·sin37t`，中心游移 ±60/±36px（原 ±40/±26）。试过更大（±0.16、±90px）会冲到 1.22，画面发晃，回调。
- 余烬 28→49 颗（左 20、右 20、中 9），亮核 r 2.6–5.4，光晕 α0.32、3.6 倍，闪烁 `0.3+0.7|sin|`。
- 手印忽明忽暗：每个手印叠一块 r=105 的暖色径向渐变（lighter），α=0.2·clamp(0.5+0.9·noise(7t+3.7k))，各自独立相位。
- 野牛/马颠簸 ±3→上下 9px、左右 ±3px，头部摆 ±0.12rad。
- 猫头小动作（对原片 65–81 帧）：lt 1.08–1.35 用 `sin(πq)` 包络，绕颈点 (596,680) 抬头转 −0.16rad，RIG.cat look 推 1.5，耳朵 60Hz 微抖 ±0.06rad。
- 结果：**0.62 → 1.06**（原片 0.86）；每帧 max 22ms。

## 少女的时代化
红赭石 `#9c3520` 剪影（脸/颈/手臂/小腿），侧脸只留一只杏仁眼（米白眼白+黑瞳+一根睫毛，眨眼变弧线）——这一笔是「少女感」的关键；金发用黄赭 `#cf8f2c` 填 + 6 条 `#6e3c0e` 波浪发丝（振幅随长度增大），轮廓也是波浪；发丝下半段逐渐不跟头部旋转（HB 函数），避免喝水仰头时整片头发甩动。及膝兽皮外衣 = G.torso + 自画下摆（每 15px 一个 ±16px 锯齿毛边），`#b06a2c` + 26 个「圆斑+7 个小点」豹纹斑 + 18 道短毛线，接缝靠「先描两块的边再一起填」盖掉。

## 仍可改进
- 少女身体是 RIG 的写实曲线，比真正岩画人形「太顺」；更原始的做法是把轮廓点降采样到 12–16 个再加大手绘抖动。
- 岩壁浮雕是静态的，火光只改亮度不改阴影方向；真要「火光跳动下岩面起伏在动」需要两张不同光向的 shade 图按火光插值（+1 次全屏合成）。
