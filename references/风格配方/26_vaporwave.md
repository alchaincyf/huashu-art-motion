# 26_vaporwave · 2011 蒸汽波 / 赛博霓虹

**中文** · [English](../en/style-recipes/26_vaporwave.md)

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/26_vaporwave.js`。

实验时的文件名：`scenes/c5_vaporwave.js`（约 210 行）。审片红灯：上衣第一版是粉色，和粉调肤色混成一片，读起来像没穿衣服。改成薰衣草紫风衣 `#8f7cf6`＋白三角领＋青色拉链线。每帧中位 49ms；帧差 25%（VHS 后期让全屏都在动）。

**管线**：整幅先画进离屏 S，再做 VHS 后期输出到 c（计数器由引擎画在最上层，不受色差影响）。
1. 墙：深紫纵向渐变 `#0d0322 → #4a0f6a` ＋ 窗口处洋红径向光、招牌处青色径向光。墙脚一条青色灯带。
2. **`glowLine(c, col, w, blur)`**：同一路径先用 shadowBlur 描粗的辉光，再描 2–3px 近白芯线，就是霓虹灯管。
3. 窗里落日：太阳是黄 → 橙 → 洋红竖向渐变，用 `destination-out` 切 7 条横缝，缝宽随深度变大（2 + q²·16），整体以 0.9/s 上移。地平线是线框山（洋红辉光），下面是青色透视网格往观众方向滚，左右棕榈剪影摇。
4. 地面：洋红透视网格，消失点 (960,600)，横线 `y = 600 + 520/d`、d = k + 1 − phase（phase = 1.3t mod 1），线宽随近处加粗。
5. **霓虹招牌「カフェ」用折线自己画灯管**（不依赖字体）：每个假名 1–3 笔，(u,v) 单位坐标。逐字按帧哈希闪：`hash(floor(30t), k) < 0.07` 灭；「フ」额外在 `f mod 17 < 5` 时 22% 概率灭，灭时画暗紫灯管。
6. Win95 对话框 TEA.EXE：灰体、海军蓝渐变标题栏、进度块 `3 + 14lt` 格、百分比 `18 + 70lt`。桌上大理石胸像（侧脸剪影 22 点、紫灰渐变＋静脉线＋粉色轮廓光＋墨镜梗）。
7. 角色：粉毛衣、青色百褶长裙、金发＋粉发圈。辉光轮廓「朝窗一侧粉、背面青」：同一组路径描两次，分别 clip 在左右半屏。

**VHS 后期 `vhs(c, S, t, lt)`**
- RGB 分离：对每个通道，把 S 画进临时画布、`multiply` 纯色 `#ff0000/#00ff00/#0000ff` 取出单通道，再以 `lighter` 错位合成到黑底。错位量 3 + 1.5sin(7t)，偶发（hash<0.12）+6。
- 跟踪噪声带：70px 高，`(520lt + 200) mod (H+160)` 下滚。带内每 6px 一条横向错位 `±30·sin(πy/bh)`，叠 90 条白灰噪线。
- 扫描线：4×4 tile pattern（第 0 行 α 0.28、第 2 行 α 0.12）。OSD：PressStart2P「PLAY」＋手画 ▶（字体里没有这个字形），16 帧一闪；左下日期、时间码按 lt 走。

**色板**：洋红 `#ff4fd8`、热粉 `#ff2f8f`、青 `#3ff6ff`、深紫 `#12052a / #2a0b4a`、日黄 `#ffd84a`、橙 `#ff8a3a`。

**坑**
- 全角「ＶＡＰＯＲＷＡＶＥ」、▶、日文在 `lib/fonts` 里都没有，会静默回退系统字体。标签改用半角＋字距 7，▶ 和假名都自己画。
- 人物描边用的是部件路径，腰线、手臂和躯干的交界也会发光。霓虹线稿能接受，但想要纯外轮廓，得先把剪影画进离屏，再描离屏的边缘。
