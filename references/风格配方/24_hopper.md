# 24_hopper · 1942 霍珀美国现实主义（硬光块面）

**中文** · [English](../en/style-recipes/24_hopper.md)

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/24_hopper.js`。

实验时的文件名：`scenes/c3_hopper.js`（约 150 行）。每帧中位 13ms（首帧 54ms）；帧差 6.0%。

**核心手法「双版本裁切」**：同一个 `room(g, K)` 函数按两套色画两张缓存——背光版 `SH`（冷绿墙 `#5d8679`、暗地板 `#5b3d2b`）和受光版 `LT`（暖黄墙 `#efcf8f`、亮地板 `#c98b52`）。每帧先画背光版，再用会移动的光斑多边形 clip 进受光版，光影边缘天然是硬的，还能整体平移。人物和家具同理：`girl(c, K, G)` 用背光色画一遍，再 clip 进斜光带用受光色画一遍。

**光斑几何**（dx = 30 − 95·easeInOut(lt/1.25)，1.2s 里左移约 95px）
- 墙上光斑 WP：(1420+dx, 250) → (1920, 470) → (1920, 730) → (1420+dx, 730)
- 地上光斑 FP：接在墙光斑下面，往右下方展开
- 人物光带 OP：左缘从 (1345+dx, 0) 到 (1185+dx, 1080)。光边在这一段里扫过少女的脸，从半脸背光到全脸受光
- 窗棂影：竖条 24px ＋ 一条平行于光斑上沿的斜条
- **人在墙上的投影** = 人物剪影平移 (+150, +18) 后画进离屏，`source-in` 填进背光底版，再画回光斑区域。效果就是光斑里透出背光墙，和人物姿态同步。

**母题动画**：光斑缓慢移动（核心）；窗外对街红砖楼（致敬《星期天的清晨》）的理发店旋转柱，红蓝斜纹以 60px/s 上行；卷帘拉绳 `sin(4.2lt)·0.07rad` 轻摆；光带里 26 颗浮尘（只在光边右侧显示）；热气。

**质感**：油画拖笔用竖向拉长的 fbm（x·0.06, y·0.006）为主、斜向为辅，1/4 分辨率生成后放大，`soft-light` α 0.2。窗外每个窗洞右侧画 10px 硬影，卷帘拉到不同高度（0.25–0.7），这是霍珀的细节。

**色板**：背光墙 `#5d8679`、护墙 `#4b6d63`、地 `#5b3d2b`；受光墙 `#efcf8f`、护墙 `#d8ad68`、地 `#c98b52`；裙 背光 `#7a2c2a` / 受光 `#cc4a3c`；金发 背光 `#a8893f` / 受光 `#f3d67e`；砖 `#b4553a`。

**坑**
- 刷痕第一版用横向 fbm、α 0.35，墙面像水纹大理石。霍珀的墙是平的，刷痕只能若有若无。
- 改代码时把注释插进一行中间，把同一行后半截代码注释掉了（Python 批量替换时注意）。

**角色**：第一版是盘发＋红长裙，审片说「像成年女性，读不出 17 岁」。改成披肩长发（`hair:'long'`）＋一条蓝发带，就年轻了。猫的白胸用平滑椭圆，背光白 `#dcd6c8`（第一版 `#c4bdac` 读成灰白猫）。

**仍可改进**：猫全程在阴影里，偏暗（这是孤独感的取舍）。也可以给猫一小块从后窗进来的光。
