# 22_constructivism · 1924 俄罗斯构成主义海报（罗德琴科 / 李西茨基）

**中文** · [English](../en/style-recipes/22_constructivism.md)

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/22_constructivism.js`。

实验时的文件名：`scenes/c1_constructivism.js`（约 175 行）。每帧中位 5ms；帧差 3.6%。

**管线**
1. 底版全缓存 `cs_bg`：米白旧纸（`P.texture` `#e9dfc4`，dark `#d9c9a4`）→ 左侧斜黑条（rotate −0.5）、红方块（rotate 0.26）、5 行「正文」黑条 → 右侧细斜线、红圆点、黑竖条里竖排几何字「ЧАЙ」→ 人物头后大黑圆（中心 (1330,395)，r 215）→ 斜红地面 (0,905)→(1920,856)，上沿一道 12px 黑线 → 窗 → 黑桌（红边、斜撑）→ 黑块凳。
2. **窗＝照片拼贴**：先在离屏画灰度「照片」（天空渐变 `#5e5e5e→#e8e8e8`、径向白云、暗色厂房剪影、烟囱），再用 `halftone()` 网点化（cell 7，gain 0.8）；舒霍夫塔用清晰黑线画在网点上面（五节双曲面，每节两组各 18 条直母线，相位差 ±1.1rad，背面 sin<−0.2 的省掉），这正是「照片＋手绘」拼贴。
3. **皮肤＝网点照片**：脸、颈、手先画灰度渐变（前亮后暗，`#fafafa→#9c9c9c`）到离屏，再网点化（cell 4.6、gain 0.74、45°）。网点下垫米白，外圈先描 7px `#fbf7ea`，这一圈就是照片剪下来的白边。五官用清晰黑笔补，嘴唇手工上红。衣服全是剪纸平涂＋3px 黑线；阴影用 `shadeDots()`，在路径内按函数落网点。

**关键函数**
- `halftone(c, src, bx,by,bw,bh, cell, col, gain, ang=π/4)`：在旋转网格上采样 src 灰度，点径 = cell·gain·√(1−L)，只落在 alpha>128 处。**所有点并成一条 path、只 fill 一次**。脸部约 3000 点，耗时 <2ms。
- 几何西里尔字：5×7 模块，每个字母是若干矩形或多边形（Й 的斜笔是四边形，短音符是上方一个小矩形）。**每个部件单独 fill**。

**母题动画**
- 李西茨基红楔刺入黑圆：顶点沿 0.34rad 轴线往返，`70·(0.5−0.5cos(2π·1.6·lt))`。
- 黑圆外的红虚线环：dash [46,22]，`lineDashOffset = −260·lt`。
- 塔顶无线电波：4 道红弧，`r = 18 + ((1.4lt + k/4) mod 1)·230`，α 和线宽随相位衰减。
- 地面标语「ПЕЙТЕ ЧАЙ!」：逐字盖章（第 k 个字在 0.045k 秒起跳，0.12s 内从 1.5 倍缩回 1），之后整排波浪跳 `−10·max(0, sin(11lt − 0.8k))`；每第 4 个字是黑字。
- 头巾两条尾巴 `sin(9lt)·6` 轻摆；杯上热气是三条黑折线上行。

**角色**：共青团少女——红头巾（头部局部 13 点，前沿后移到能露出金色刘海，颈后打结两条三角尾）、白衬衫＋红领巾三角＋红袖口、深灰长裙（网点阴影）。猫用剪纸橙 `#e2741c`＋米白，10px 黑条纹，尾巴用虚线描边做虎斑，眼睛是方瞳竖条。

**色板**：纸 `#e9dfc4`；红 `#c8231c`／`#8f1711`；黑 `#151311`；米白 `#f4ecd6`；金发 `#e3b03e`／`#a87a1c`；猫橙 `#e2741c`。

**坑**
- 「Й」的短音符第一版画在字格上方（y=−1.7u）：竖排时被上一个字母盖住，地面标语里被裙摆盖住，审片读成「ЧАИ」。改成整个字画在 7 格内（И 部分下移 1.7 格），标语也改到角色之上画（海报字压人物）。
- 「А」第一版用两条反向斜腿＋横杠拼在一个 path 里，重叠处被 nonzero 抵消，竖排时读成「В」。改成逐部件 fill。
- 地面标语第一版基线压在 y=1060，字的下半截出画。按 `translate(x, 990)` 以字中心定位。
- 颧下阴影第一版太重，网点化之后像一片胡子。灰度源里的阴影 α 要比平涂时低一半。

**仍可改进**：罗德琴科更典型的是「人物照片＋喇叭形文字锥」。可以把热气换成从杯口放射出的红黑楔形字锥。
