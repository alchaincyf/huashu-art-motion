# 32_rembrandt · 1642 伦勃朗明暗法

**中文** · [English](../en/style-recipes/32_rembrandt.md)

> 来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/32_rembrandt.js`。

实验时的文件名：`scenes/r1_rembrandt.js`，每帧约 47ms。

**管线**：亮态底稿（按"全亮"时的颜色画房间、铅条菱格窗、土耳其桌毯）→ 褐色大笔触重画背景，再糊 2.2px 叠 75%（揉开的底子）→ 桌毯单独一层、细笔触 → 角色平涂＋体积渐变＋细笔触 → 角色"失边"处理 → **光照图 multiply** → 窗玻璃 screen 提亮＋云影掠过 → 鬃毛厚涂 → 烛焰、光柱浮尘、热气 → 龟裂、颗粒、暗角缓存层＋soft-light 金褐釉。

**关键参数**
- 光照图：底色 rgb(30,21,13)，相当于环境光 0.13。用 lighter 叠：
  - 光柱：楔形多边形，模糊 40px，缓存，α 0.8–0.95。
  - 窗本身：r330。
  - 脸池：r250 α0.95。胸：r230 α0.55。猫：r240 α0.8。桌面：r280 α0.6。
  - 烛光：r190+40·fc，α 0.6+0.4·fc。
  - 少女背后墙面的"分离光"：r300 α0.35。伦勃朗常在人物暗侧后面把墙打亮，好把人从背景里分出来。
  - 叠完整幅 multiply。
- 摇曳：`flick(t) = 0.5·noise(2.2t) + 0.25·noise(6.5t)`；光池中心随 noise(0.9t) 漂移 ±14px；云影 `cloud = 0.5 + 0.5·sin(2.2t − 0.6)` 让窗光 ×(1 − 0.35·cloud)，同时一团暗色径向斑以 260px/s 横穿玻璃。
- 背景笔触：cell18、len54、w16，jitter 6，角度 −0.9 + 1.6·noise(0.003)；色板 mixBase 0.7。
- 失边：角色层先 blur(2.4px) 全不透明画一遍，再叠 α0.62 的清晰层。暗侧会融进背景，五官还认得出。
- 厚涂（鬃毛笔）：一笔 = round(w/1.3) 条平行细鬃，每条亮度 ±17、两端随机缩 0–25%、线宽 1.4–2.6；下侧一条 α0.28 的投影；上侧撒 2+w/3 个亮点。只用在受光处：金发、领口、瓷杯、珍珠、猫白胸、猫头顶。
- 罩层：龟裂 α0.28×0.28；颗粒 density 0.05 α0.12；暗角 0.75；soft-light rgba(200,140,60,.35)。

**母题动画**：烛焰（noise 驱动左右倾、高度跳）、窗光被云影遮暗再恢复、光柱里 70 颗浮尘（只在光柱内显示，24 帧闪烁）、端杯、热气。运动面积 8.0%（0.45↔1.0s）。

**坑**
- 厚涂第一版画成"暗影偏移＋主笔＋亮脊"三条整齐的线，读出来像白色贴纸/创可贴。改成鬃毛笔才像颜料。
- 拷回原图的局部区域（`drawImage(b, x,y,w,h…)`）会把未刷笔触的背景一起带回来，形成矩形补丁。道具应该单独一层画在笔触之后，不要拷区域。
- 颗粒 density 0.12 / α0.22 会让脸上全是脏点，0.05 / 0.12 刚好。
- 手要在杯子之前画，不然手的椭圆把瓷杯盖掉了。drawGirl 里的顺序是"手→杯→拇指"，自己重画时要照这个顺序。
