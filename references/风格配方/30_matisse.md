# 30_matisse · 1947 马蒂斯《爵士》剪纸

**中文** · [English](../en/style-recipes/30_matisse.md)

> 来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/30_matisse.js`。

实验时的文件名：`scenes/k4_matisse.js`（167 行）。每帧约 25ms，帧差 9.3%。

**构图**：墙＝《波利尼西亚》双蓝棋盘（`#1d4fb8 / #4f95dc`，每格 240×236 剪纸块），窗＝《伊卡洛斯》（钴蓝底、黑人形、红心、黄星），地＝翠绿 `#1f9a5a` 加黑踢脚条，桌面是黑剪纸，椅子是黄剪纸。

**手法**
1. **剪刀折线 `cut(pts)`**：沿轮廓每 14–24px 取一个点，加 ±2–2.5px 种子抖动，点与点直线相连。自己生成的形状一律这样处理。
2. **海藻（关键）**：一根锥形茎，加 2×lobes 根左右交替的**圆头胶囊手指**。手指角度 `±(1.05−0.55u)`，长 `width·(1−0.45u)`，宽 `width·(0.34−0.12u)`。所有子路径 `addPath` 进同一个 Path2D，用 nonzero 一次填充，得到并集，投影也只算一次。**不要用「沿脊线调制宽度」**：第一版这样做，出来的是毛毛虫和 Z 字闪电。
3. **RIG 角色手剪边**：RIG 不给点列，所以角色层整层做像素位移。静态位移场是 `fbm(0.028x, 0.028y, 2)·9`，dx、dy 各一套，只处理 bbox (330,470)-(1600,980)，约 15ms。
4. **纸的投影**：shadow 偏移 (5,6)、blur 4、`rgba(10,20,40,.3)`，表现钉在墙上的纸。
5. **水粉刷痕**：缓存 2600 道长条笔痕（60–300px、宽 6–22、黑白各半、α .04–.13、倾斜 −0.25rad），整幅 `overlay`。

**母题动画**：
- 海藻像纸片一样绕根部摆 `sin(2.8t+φ)·0.13`，卷边用 `scaleX 0.93–1.0` 呼吸。
- 伊卡洛斯：7 颗不规则黄星，转着闪（scale `.82+.22sin(7t+1.9k)`）；黑人形上下漂；红心跳（`1+.18·max(0,sin 9t)`）。
- 两只白鸟扑翅（scaleY `.55+.45cos 13t`）。
- 一片粉纸翻飞落下（scaleX=cos 6t）。
- 热气是两根白色小剪纸。

**角色**：马蒂斯《罗马尼亚衬衫》。白宽袖衫，前襟一条钴蓝刺绣带（红黄交错的小三角），袖上随手臂旋转的红/蓝刺绣横带（clip 在 upperArm 里），红长裙＋黑腰带，金发是 5 个剪纸卷团。五官只用剪纸碎片：黑杏仁眼、红唇三角、粉腮圆片。
**坑**：飘落的纸片第一版轨迹划过少女的脸，改到左墙。计数器底下垫一张白剪纸片，否则黑字压在钴蓝上看不清。
