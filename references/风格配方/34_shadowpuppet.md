# 34_shadowpuppet · 中国皮影戏

**中文** · [English](../en/style-recipes/34_shadowpuppet.md)

> 来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/34_shadowpuppet.js`。

实验时的文件名：`scenes/r3_piying.js`，每帧约 121ms（每块皮件单独离屏，multiply 次数多）。

**管线**：影窗（油灯在幕后的径向暖光＋screen 灯芯热点＋3px 布纹，布纹缓存）→ 道具层（窗棂、桌、瓶花、方背椅，缓存）→ 蝴蝶 → 猫 → 少女，每组一张离屏层 → 每层先印一层偏移软影，再 multiply 本体 → 铆钉 → 操纵杆 → 木框。

**关键参数**
- 皮件函数 `piece(g, path, col, carve)`：
  - 填色。
  - 在 clip 内用 destination-out 刻纹。
  - 在 clip 内描 2×edge 宽的同色"皮边"，保证刻纹不会刻穿外轮廓。
  - 描 2.6px 深褐边 #3a160a。
- 刻纹库：
  - 鱼子纹 dots：s14–22，r3–3.5。
  - 团花 flowers：5 瓣椭圆，s36–46。
  - 云纹 clouds：阿基米德小螺旋，线宽 3.4，s24–40。
  - 方格 lattice：s26–32。
  - 刻线 lines：线宽 3–7。
- 印到幕布：`stamp(layer)` 先 multiply α0.28、blur 6px、偏移 (7,5)，表示皮件没完全贴紧幕布时的虚影；再 multiply 本体。透光 = 幕布色×皮色，重叠的皮件自然变深。
- 颜色：红 #c0352a、绿 #2f7d4c、琥珀 #d99a2e（金发＝琥珀色皮）、黄 #e2bd4a、蓝 #2c5a8a、橘 #d9782a（猫）。
- 幕布：径向 #fff6d6 → #f2d7a0 → #cf9a58 → #7a4a20；灯焰扰动 `fl = 0.5·noise(3ts) + 0.3·noise(9ts)`，ts 按 15fps 步进。光心漂移 ±26/±18px，热点半径 260+40·fl。
- 旦角"空脸"：头发画完后 destination-out 掉整张脸，只描脸部轮廓，再补凤眼（上挑长线＋下眼线＋点睛）、柳叶眉、点唇。
- 橘白猫的映射：橘色 = 橘皮；白胸、白口鼻、白腿白爪 = **整块镂空只留皮边**；虎斑 = 刻线。这条对所有"剪影/镂空类"风格都适用：白色部位直接镂空。
- 动作：
  - 少女整体绕 (1260,930) 摆 ±0.012rad；头绕颈部铆钉转 ±0.06。
  - 端杯按 10fps 步进。
  - 手腕松：dangle = 0.35·sin(11·ls)·(1 − 0.6·cup)，杯子跟着手一起甩。
  - 猫头绕颈点头 0.1·sin(6ts) + 0.05。
  - 尾巴 4 节铰链，每节相对上一节转 0.3·sin(7ts − 0.9i) + 0.38，鞭梢一节节滞后。
  - 步摇珠串甩动。
- 杆子：5px 深褐线，blur 1.2px multiply，从颈、腕、猫背、猫头、蝴蝶通到画面底边。

**母题动画**：灯焰让整块幕布的光斑跳、蝴蝶（翅膀按 12fps 用 scaleX 翻面，带杆子）、手腕甩、猫点头和尾巴鞭梢、步摇。运动面积 6.8%。

**坑**
- 桌腿压在裙子上：multiply 后红×绿接近黑，变成一块黑梯形。皮影里重叠变深是对的，但别把重叠放在视觉焦点上，把桌腿挪开就好。
- 猫前腿第一版是一整块橘色矩形，盖住了白胸。改成两条几乎全镂空的白腿才读得出"橘白"。
- 杆子横穿主体会很乱：杆子从皮件往下、往外走，不要跨过别的角色。
