# 03_greek · 公元前530 阿提卡黑绘陶器 —— 代码画法笔记

**中文** · [English](../en/style-recipes/03_greek.md)

文件：`scenes/03_greek.js`（纯 Canvas 2D，无图片）。最终自检：warm max 15.9ms / mean 7.6ms / cold 80ms，确定性通过，0.2↔0.7s 运动差分 22% 像素在动。

## 一句话诀窍
黑绘 = **黑釉剪影 + 刻线 + 附加色**三件套，缺一不可：
- 剪影：所有人/物填 `#1b120d`（近黑带暖），不描边，靠剪影和陶土底对比成形。
- 刻线：在黑剪影上「刻穿」，用陶土亮橙 `#e8904c` 画 1.5–2px 细线（衣褶、五官、肢体重叠处的分界）。
- 附加色：紫红 `#8a2a37` 色带（发带、袖口、下摆、项圈、坐垫）＋白色小点（`#f6ead6`，r≈2，间距 11–17px）。
做到这三样，不需要任何纹理就一眼是希腊陶瓶。

## 色板
陶土 `#dc6a2f`、亮陶土（瓶面板）`#e8803f`、黑釉 `#1b120d`、紫红 `#8a2a37`、白 `#f6ead6`、刻线 `#e8904c`、金发 `#f2bd48`、陶土留白（猫白区）`#f3cfa4`、猫橘 `#f2913f`、猫鼻 `#e7897a`。

## 管线与参数
1. **陶土底（缓存 `gr_bg`）**：480×270 低分辨率逐像素算 fbm(×0.016, 4 octave) 斑驳 ±30 ＋ `noise(x*0.006, y*0.85)` 的**水平条带噪声**（拉坯纹）±9，放大到 1920×1080（低频本来就糊，省 16 倍计算）；再画 560 条随机水平细线（长 150–1050，alpha 0.03–0.08，深/浅两种）当拉坯细纹；420 个深色小点 + 120 个浅点；两层 `P.grain`；5 条裂纹（每 9px 一段、±2px 抖动，下沿再画一条 1px 偏移的淡亮边，裂缝立刻有厚度）。中心叠一层暖色径向提亮 0.16。冷启动整帧 ~80ms。
2. **暗角（缓存 `gr_vig`）**：径向 380→1180，外沿 rgba(30,6,0,.62)，最后一层盖全画面（含纹带）。
3. **静态黑绘层（缓存 `gr_static`）**：画框（黑边 18px＋白点串 11.6px 间距＋内细线）、葡萄藤（正弦茎＋三角葡萄串 3-2-1 圆点）、桌（腿带兽爪脚）、车旋椅腿（宽度表 [y,w] 折线对称成形）、天鹅颈椅背（13px 粗描边曲线＋椭圆头＋三角喙）、双耳瓶（24 点对称轮廓→`RIG.smooth`，瓶面板留陶土＋小黑猫、瓶底射线纹、一条竖向 0.09 的光泽渐变）、两段希腊铭文。
4. **希腊铭文**：字体库没有希腊字形 → 自写**笔画表**（每个字母 1–3 段折线，单位格 0..1）。字高 30、笔宽 3.4、每字高度 ×(0.9–1.06) 随机、基线 ±6% 抖动、顶点 ±0.7px 抖动；Ο 画成小圆（字高 0.25，原片就是小 o），Ι 宽 2px。手写陶画铭文味道主要来自「字母不等高 + 小 o」。
5. **滚动纹带**：顶部回纹（周期 60px，7px 黑线，单元折线 `[[4,46],[4,0],[50,0],[50,34],[18,34],[18,14],[36,14],[36,22]]` ＋通长底线）与底部莲苞链＋射线纹（周期 76px＝两个 38px 单元，奇数苞填紫红，所以真实周期是 76）各预渲成宽 W+2P 的条带，每帧 `drawImage(strip, -(off mod P))`。偏移曲线：
   - 顶：`off = 22·lt + 60·easeInOut((lt−0.49)/0.35)`，向左；
   - 底：`off = −(18·lt + 76·easeInOut((lt−0.477)/0.367))`，向右。
   原片只在 169–191 帧做一次 easeInOut 周期跳；我额外加了 18–22px/s 匀速漂移，让本段前 0.47s 也能看出在走。
6. **画框内母题**（每帧画，clip 进画框）：6 条海豚（自写贝塞尔剪影：喙、背鳍、腹鳍、尾叉＋腹部刻线＋白眼点）沿自身朝向 ±9px 来回游、角度 ±0.12rad，周期 0.85s，彼此相位差 1.3；船整体绕 (560,420) 起伏 ±4px、摇 ±0.025rad，周期 0.9s。白帆＋紫红缝线、新月船身＋蝎尾形船尾、紫红船舱、斜倚人形。
7. **里拉琴**：以钉子 (1050,150) 为轴 `0.09·sin(2π·lt/0.8+0.5)` 摆（±5°，音箱处位移 ±17px，1 秒内明显）。龟壳音箱＝黑圆＋刻线圈＋5 个刻线小圆。
8. **玫瑰花饰**：8 瓣黑椭圆＋刻线分瓣＋紫红心，`lt·1.6` rad/s 正反交替旋转。
9. **橘白猫**（自画，不用 RIG 默认多边形；尾巴用 `RIG.cat` 的 tailPts 跟 choreo.tail 摆）：整体以 (548,903) 缩 0.9 落进标准框；橘剪影＋黑描边 3.4px；白胸/白爪/口鼻用「陶土留白」奶油色；**背部虎斑沿背轮廓按弧长等距取 12 点，朝身体中心 (575,800) 画锥形斑**（长 30–48，根宽 10）——比手摆斑纹自然得多；大腿弧、前腿竖斑；古风大圆眼（白眼＋黑瞳＋高光＋上方一道眉弧），眨眼时换成弧线；紫红项圈白点。
10. **少女**：`RIG.girl({cup,sip,breathe,s:0.97,dy:-14,hair:'long'})`——缩放下移让脚落在地线 903。
    - 身体直接填 RIG 的 Path2D（farSleeve/skirt/torso/neck），远侧手换成小椭圆（RIG 的 farHand 在黑剪影里像一片刀片）。
    - **头部自画**：在 RIG 静止坐标系里写希腊侧脸（直鼻梁连额、细下巴）＋发型轮廓，用 canvas 变换复刻 RIG 的头部运动：`translate(neck)·rotate(G.tilt)·translate(−neck)·T`。同一个矩阵用 `DOMMatrix` 再算一份，`Path2D.addPath(faceSil, M)` 拿来做刻线裁剪区。
    - **金发**（认出「金发少女」的关键）：发区 clip 内画 11 条头顶波浪发丝（二次贝塞尔＋法向 2.6px·sin(7πu) 波动）、8 绺背后长卷发（正弦 4.5 个半波＋末端小螺旋）、发髻双螺旋、额前 4 个小卷、鬓角两条螺旋卷（黑底 6px 垫一道再画金 2.2px，跨出剪影也看得清）。金线 2.5px 在 1080p 下才够「量」，2px 时缩略图里就看不出是金发。
    - 刻线：衣褶 16 条（clip 在身体内）、杏仁眼（浅色眼白＋黑瞳，正面眼画在侧脸上）、眉、鼻翼、唇、下巴。**近侧手臂与身体/头重叠处的分界**：clip(身体∪头) 后描手臂轮廓的刻线——黑叠黑只能靠这个分开，手举到嘴边时脸才不会糊成一团。
    - 附加色：下摆 15px 紫红带＋白点、袖口带（clip 在上臂内，沿上臂法向画 15px 宽色带＋上下刻线）、手镯、白点四瓣小花 8 朵、发带。
    - 基里克斯杯（宽浅双耳，半宽 32）跟 `G.cup`（含 tilt），杯口紫红线；热气是三道「≀」黑细线，相位 `t·9`。

## 动的东西（0–0.94s 内都可见）
端杯（choreo.cup 0.9s 举到嘴边＋头微仰）、猫尾/眨眼/呼吸、顶底纹带滚动（漂移＋拍点周期跳）、里拉琴摆、船起伏、海豚游、玫瑰转、热气扭。

## 踩到的坑
- RIG 头发轮廓直接放大后后脑太宽（第一版后脑伸到 x=1450，头像头盔）；按设定稿收到 1424，长发只垂到 y≈558。
- 杯子在嘴边时黑手黑杯黑脸糊成一块：①手臂对头部做刻线分界 ②杯子缩小（半宽 44→32）③杯口留一条紫红线。
- RIG 猫的头顶到 y=535，标准框猫顶是 610；不缩会压到画框下沿。
- 底带奇偶苞交替时真实周期是 2 个单元（76px），预渲条带的 wrap 周期必须用 76，否则每 38px 跳色。
- `P.grain` 的种子 = key 长度，两层 grain 的 key 必须不同长度，否则图案相同。
- **端杯终点要时代化（复核返修）**：RIG 的 cup→mouth 终点在鼻尖附近、杯倾 −0.45rad，换成宽浅的基里克斯杯后像一根鸟嘴/烟斗插在脸上，手还捂住嘴和下巴。改成自己做 IK：唇点 rest(1243,391) 用头部 DOMMatrix 变换到屏幕，杯沿中心 = 唇点 −(30,−1)（杯沿右端刚碰嘴唇），倾角 −0.08·cup（≤5°），手的 IK 目标 = 杯沿 +(lerp(32,6,cup), 30)，即托在杯脚下；`RIG.ik2(S, 手目标, 165s, 122s, −1)`＋`RIG.taper` 自己出上臂/前臂。前臂竖在胸前，鼻、唇、下巴的侧脸轮廓完整露出。热气跟随杯沿。

## v1 审片返修（猫改黑绘 + 顶带滚动加量）
- **猫必须和人同一套画法**：亮橘大圆眼卡通猫在黑绘里一眼跳戏。改成黑釉剪影，「橘白」只靠附加色和刻线分区：背部沿轮廓画一条 26px 紫红鞍带、头顶一块紫红（椭圆 46×22 clip 在头内）、尾巴黑底＋7px 紫红芯；虎斑全部是陶土橙 `#f2913f` 3px **刻线**（沿背轮廓弧长等距 14 条朝身体中心的弯线＋大腿 3 条＋前腿 3 条＋尾巴每隔 2 点一道环）；白胸/口鼻/爪用白彩 `#efe1c8`，爪上黑刻趾；眼睛改古风刻线杏仁眼（白彩眼白＋竖椭圆黑瞳＋眼尾小刻线），眨眼是一道下弯刻线；鼻子紫红，须左侧用刻线（落在黑脸上）、右侧用黑线（落在陶土上）。
- **周期图案滚整数个周期 = 首尾两帧一样**：顶带 60px 周期跳一次后画面和跳之前完全相同，看静帧对比或抽帧很容易判成「没动」。匀速漂移从 22→48px/s（底带 18→30px/s），保证任意两帧间都有相位差。
- 整片静止段运动量（480×270 帧差均值）：03_greek 1.87 → 2.02，原片 2.06。warm max 17ms。
