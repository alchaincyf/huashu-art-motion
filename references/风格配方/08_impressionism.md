# 08_impressionism · 1874 印象派（莫奈）

**中文** · [English](../en/style-recipes/08_impressionism.md)

每帧 65–76ms（中位 69ms）。主要开销是两遍全屏 P.strokes 加一遍角色笔触。

## 管线（照 09_postimp 标杆）
1. 平涂底稿 `impBase`，每帧重画，因为罂粟、云、花束、盆栽、窗帘都在动：
   - 粉紫墙（#d8bede→#f0c8cc→#f2c4d4），右上叠一个 r=900 的暖黄阳光径向渐变。
   - 窗外花园：天、树林、红顶屋、草地，70 朵罂粟（茎底不动，花头横摆 `sin(t·3.2+ph+x·.02)·(6+r·.6)`），撑阳伞的女子加孩子（向《罂粟田》致敬），花丛。
   - 白窗框、淡紫窗帘、墙上的《日出·印象》、圆桌白紫桌布、花瓶、茶壶、右侧盆栽（整团叶子随 `sin(t·1.9)·8` 摆）。
2. 笔触重画，**两遍**：
   - 主画面：cell 11、len 20、width 7、outline 0、jitterCol 26，用 mask 排除窗景和墙上的小画。
   - 窗景和《日出》：cell 6、len 11、width 4.5，只画 mask 范围内。
   - 第一版只有一遍粗笔，窗外的房子、撑伞女人全被糊掉，《日出》也被斜笔刷成一片。分开两遍、《日出》改成横向水波笔后就都认得出了。
   - 画布先铺 #f2e6ee，笔触缝隙里露出浅色底。
3. 方向场：墙向右上斜（阳光区 −0.95 弧度，其余 −0.55，再加 ±0.55 噪声）；地面接近水平；窗帘和桌布竖向；盆栽从盆口往外放射；窗里的天空横向。
4. 区域色板 `P.swatch`（mixBase 0.3–0.45）：墙 9 色粉紫黄；阳光墙 7 色奶黄；地面 7 色玫瑰橙紫；天空、草绿、窗帘淡紫、桌布蓝紫各一组。白窗框用 `col > (240,236,225)` 判定，混回白色，否则会被刷成墙色、窗框消失。罂粟的红返回 null，保留底稿原色。
5. 角色：先用 `RIG.drawCat` / `RIG.drawGirl` 的 fill 模式平涂，再在角色层上用 `source-atop` 跑一遍 P.strokes（cell 7、len 13），只在角色内部出笔。白裙用白、淡紫、奶黄四色抽色。之后只补五官，用淡紫细线，印象派不勾轮廓。
   - 草帽、蓝丝带、腰带飘带都在飘。
   - `pal.line` 一定要设成发色金：drawGirl 的 locks、lid 这些部位即使 lw=0 也会用 pal.line 描线，默认的深蓝会在脸旁边留下黑道。猫同理，要设 `line`/`whisker`。

## 母题动画
- **阳光斑闪烁跳动**：26 个斑块（6 块在桌面，20 块在地面）。每块的强度是 `0.5+0.5·sin(t·sp+ph)·sin(t·sp·0.53+2ph)`，再用 clamp 截断，所以亮灭的节奏不规则。斑块缓慢横漂 ±10px。每块是 40 笔亮黄白短笔，按 8fps 换种子沸腾。第一版用 screen 叠加、α0.75，在粉底上几乎看不见，改成 source-over、α0.95 才够亮。
- 墙上阳光区有 60 根斜向亮笔，按 6fps 换种子闪烁。
- 猫毛闪光：60 个候选点，用 `isPointInPath` 限定在猫身和猫头的左半边（受光侧），按 `sin(t·7+h·30)` 明灭。
- 全画 8fps 沸腾，热气白色。

## 性能
两遍全屏笔触加一遍角色笔触，约 69ms。转场时引擎要同时画前后两个时代，08→09 合计约 69+110ms，会超过 150ms，但只发生在转场的那十几帧里。

## v2 返修（审片：整屏每 7–8 帧笔触重洗，帧差 18）
- 笔触位置全部固定：`boil: 0`。**光固定种子不够**：P.strokes 的随机数是一条顺序流，palette 返回 null 时 jitter 会多吃 3 个数；而返回不返回 null 取决于底稿颜色，罂粟一摇、盆栽一摆，后面所有格子的笔就整体重洗。`stable(palette)` 包装成每格只吃 1 个数、永不返回 null。
- 角色笔触不用 alphaMask（端杯一动跳过的格子就变，整层重洗），改成自写循环：每格随机数用 `U.hash(i,j)`。顺带每帧从 115ms 降回 72ms。
- 「活」改由局部运动承担：光斑漂移 ±44px、明灭频率 5–11；罂粟摆幅加到 10+；云横走 45px/s；窗帘和盆栽摆动；窗外花草的笔按风向 ±0.22rad 转角；猫甩尾（×2.2）、扭头（look）。
- 静止段帧差（480×270，屏蔽计数器，去掉段尾转场帧）：v1 均值 4.14、峰值 20.5，是频闪；v2 均值 0.57、峰值 1.9。原片 0.77。
