# 23_dali · 1931 达利超现实主义（《记忆的永恒》）

**中文** · [English](../en/style-recipes/23_dali.md)

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/23_dali.js`。

实验时的文件名：`scenes/c2_dali.js`（约 235 行）。每帧中位 47ms（首帧 84ms）；帧差 4.6%。

**管线**
1. 底版拆成三张缓存，因为影子必须夹在中间：`dali_bg`（天、海、岩、地）→ 每帧画影子 → `dali_wall`（开窗的断墙残片＋枯枝）→ `dali_block`（石块桌＋凳）→ 软钟 → 角色。
2. **体积填色 `vol(c, path, x0,y0,x1,y1, a, b, occl, blur)`**：线性渐变填充，再在 clip 里用 shadowBlur 描一圈暗边做内阴影。全片无勾线，学院派的圆润感全靠这个。
3. **长影子**：把每个物体的剪影用剪切仿射投到地面，`setTransform(1, 0, −kx, ky, kx·yg, yg·(1−ky))`，yg 是该物体的着地线（墙 700、桌/猫 905、人 930）。所有剪影先画进一张离屏（纯黑），再整体以 α 0.55、blur 1.5px 叠上去，避免影子重叠处加深。用 clip 只留地面部分（y > 594）。`kx = 0.85 + 0.6·easeInOut(lt/1.2)`，影子在 1.2s 里明显变长。
4. **软钟 `softMap(o, sag)`**：圆盘局部坐标 (u,v) → 屏幕。v ≤ fold 的部分躺在台面上（y 压缩到 0.28–0.32）；v > fold 的部分垂下：`X = cx + u·(1 − flare·q)`，`Y = … + d·(0.62 + 0.3·sag) + 中央下垂高斯 + sin 波纹`。外框、表盘、12 个刻度、两根指针（沿映射采样成软线）、折线高光**都走同一个映射**。

**关键参数**：`flare = −0.12`，负值让垂下部分像软布一样往外摊开，下缘是圆的；正值会收成冰淇淋筒。drip 0.18–0.4。sag 在 1.2s 内从 0.1 → 1.4：第一版 0.35→1.0，审片说「钟没有明显在淌」。三只钟：窗台 R72、桌沿 R88、枯枝 R64（fold −34，大部分垂下）。指针转速 4.5–6.5 rad/s。

**母题动画**：三只软钟持续下垂、指针以不同速度转；地平线上的高跷象（四条细腿相位差 π/2 交替迈步，膝关节 0.52 高度处微弯，身体 14Hz 微颠，背驮方尖碑）每秒左移 70px；9 只蚂蚁绕橙色怀表做椭圆爬行；长影子变长；猫尾巴软化下垂（尾尖 y + q²·34）。

**角色**：西班牙少女，浅蓝长裙＋白翻领，金发髻，无勾线，体积靠渐变＋内阴影，五官是暗褐细线。猫用渐变橙，条纹用 blur 2px 的半透明笔（柔），眼睛用径向渐变；白胸改用平滑椭圆 (606,768) 40×92，不用 `K.white`。

**色板**：天 `#22407c → #5f88bd → #e9dcae`；海 `#8aa6b8 → #4f6f86`；岩 `#e8c27a / #9a6a34`；地 `#d2ad70 → #7a5129`；墙 `#f4ead2 → #cdbf9f`；钟金 `#f0d27c / #9a7426`，表盘 `#f6efd6`。

**坑**
- 影子第一版往观众方向投（ky>0 向下），全被画框底边吃掉。太阳要放在左前方低空，影子往右后方躺（y′ = yg − ky·(yg − y)）。
- 影子是投在地上的，必须画在墙和桌子下面，所以底版要拆层，不能一张缓存到底。
- 软钟 flare>0 加大 drip，就是冰淇淋筒。
- 这个计数器底色是深蓝天，原来设的深褐色字看不见，改成米白字＋深色投影。

**仍可改进**：人物还是偏矢量插画，可以加更细的高光和暗部反光；《记忆的永恒》里那个侧卧的软体「自画像」生物可以作为第四个母题。
