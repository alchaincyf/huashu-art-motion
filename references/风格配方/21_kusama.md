# 21_kusama · 草间弥生无限波点

**中文** · [English](../en/style-recipes/21_kusama.md)

> 来源：迁移测试 A（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/21_kusama.js`。

实验时的文件名 `scenes/05_kusama.js`（124 行）。0.45↔0.9s 为 17.3%，相邻帧中位 2.98%，JS 侧 4–28ms。

**蠕动的点**
- 所有点的半径乘同一个「从猫出发的行波」：`wave = 0.82 + 0.28·sin(dist·0.012 − 6t)`。
- 整个房间的点从猫的位置一圈圈胀缩，像在呼吸。这一个函数就让全屏都活了。

**点的布置**
- 墙：大点（30px，间距 104）＋小点（10px，错位）两套六角网格，各带 ±25–50% 抖动。每个点是轻微椭圆加随机转角，像手画的。
- 地板：9 行，越近越大（6→28px）、越疏，压成 0.42 的椭圆做透视。
- 红裙白点 13px、间距 52，按 46px/s **顺着裙子往下爬**（clip 到裙子剪影，y 偏移取模）。
- 猫：橘色区白点、白色区红点，各自往下爬。
- 脸颊上也画了一个红点（草间的身体彩绘），头上是红底白点蝴蝶结。

**无限镜屋（窗）**
- 3D 格子灯：13×7×3，6 色。z 以 0.3/s 循环飞向镜头，透视投影 F150。
- 每颗灯是实心小核加 3.2 倍光晕，lighter 叠加。
- 坑：第一版灯随机散布、光晕很大，糊成了散景。规则格子＋小实心核才有镜面无限重复的感觉。

**黄南瓜**
- 5 瓣椭圆，绘制顺序是外 → 内。
- 每瓣按行排黑点：中列最大（9.5px），向两边、上下都缩小，点的大小也跟着行波变。
- 整体呼吸：缩放 `1 ± 0.025·sin(5t)`，以底部为轴。

**结尾「自我消融」**
- lt 1.0–1.26：红色覆盖层渐显，全屏 120px 六角点阵从猫的位置一圈圈胀到 0.47 倍间距。之后约 0.15s 只剩点阵在轻轻呼吸，给结尾一个落点（审片指出第一版没有停留帧）。
- 最后一帧停在红底白点的点阵上。
- 坑：第一版让点无限胀大，结果是白屏。半径必须封顶，最后停在点阵，不能停在纯色。
- 坑：裙子和墙都是红底白点，少女在画面里会溶解掉。终版把少女轮廓线加到 4.5px，猫白色区域的红点去掉，保住橘白分界。
