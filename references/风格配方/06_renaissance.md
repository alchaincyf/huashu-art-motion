# 06_renaissance · 1503 文艺复兴盛期（达芬奇式）

**中文** · [English](../en/style-recipes/06_renaissance.md)

每帧 16–37ms（中位 16ms）。

## 管线
1. 静态层 `ren_static`：先在原始 canvas 上画完房间，再整层用 `filter: blur(1.3px)` 画进缓存，相当于全画面做一遍 sfumato。房间内容如下：
   - 墙：P.texture #43321f→#22180e，加窗光晕的径向渐变，顶部压暗。
   - 窗：半圆拱窗，石框左侧受光，窗洞里是远景。
   - 地砖：透视棋盘。按真投影算：`y = 420 + f·h/Z`，`x = 960 + f·X/Z`，f=1029、h=5.75，Z 从 16 往前每块砖 1.4。第一行落在 y=790，往下依次 825/868/922/989，和原片的行距对得上。地砖色是 #a88c64 和 #5c2418，再叠一层 soft-light 光池和一层四周压暗的径向渐变（以 760,960 为中心）。
   - 方桌白布、梯背椅。
2. 远景（空气透视）：画三层山，越远越蓝越淡（#9fb4b8 → #7d9294），轮廓用 fbm 生成。之后是湖、河谷（由灰绿过渡到暖赭）、蜿蜒的银白河（宽度随远近从 3 增到 16px）、柏树和圆树、石桥。
3. 每帧依次画：河面碎光（24 个光点顺流移动、闪烁）→ 飞鸟 → 扑翼机（三者都裁剪在窗洞内）→ 角色层 → 光柱和浮尘 → 罩层。
4. 罩层 `ren_over`（缓存后一次 drawImage）：
   - 暗角：0.55 处 α0.3，边缘 α0.8。
   - 黄釉：α0.07。
   - 画布经纬：每 3px 一条线。
   - 油彩笔触肌理：9000 笔，α0.022/0.028，线宽 5–10，方向随机。
   - 龟裂纹：P.craquelure 取 α0.32；再用 `brightness(0) invert(1)` 把它变成白线，错开 1px、α0.16、`lighter` 叠一遍，模拟漆皮翘起的亮边。

## 晕涂（sfumato）
角色先画进离屏层 `renChars`，只处理 (320,180,1200,780) 这块区域。画回主画面分两遍：先 `blur(2.6px)` 全不透明，再叠一张 α0.38 的清晰层。这样边缘是软的，五官还认得出。角色不描线，全部靠渐变出体积：
- 裙褶：亮褶 rgba(200,70,60,.3)，暗褶 rgba(40,0,0,.45)。
- 天鹅绒袖子：沿骨骼方向画一条 rgba(170,200,140,.45) 的光带。
- 脸：左侧受光渐变，加眼窝阴影。

## 母题动画
- 扑翼机：0–1.35s 从 x=470 飞到 740，同时上下浮动、略有俯仰。两张蝙蝠翼的扇动按 `up = 0.5+0.5·sin(t·12+相位)`，翼尖在 −118 到 +24px 之间。远翼缩到 0.78 倍、颜色压暗、相位错开 0.5。翼的画法：前缘梁＋6 根放射肋＋扇贝形后缘膜，尾舵也在摆。第一版是平面「纸飞机」，认不出是达芬奇的扑翼机，重画成现在的肋骨扇形翼后才认得出。
- 光柱：楔形一次性画进缓存并做 `blur(28px)`，每帧 screen 叠加。第一版每帧直接填多边形，两条硬边很假。浮尘是 46 颗粒子，沿光柱缓慢上浮并闪烁。
- 少女按编舞用银杯啜饮，cup>0.7 时闭眼。猫一直眯眼微笑，尾巴在摆。

## 坑
- 第一版油彩肌理用 26000 笔、α0.05、方向跟着 noise 走，结果整面墙像梵高的漩涡（后印象派）。降到 9000 笔、α0.025、方向随机后才回到古典油画的感觉。
- 猫身体的轮廓内侧压暗用了 26px、α0.45，奶白色身体看起来像个玻璃罩。改成 14px、α0.22，白色的胸部改用径向渐变把橘色毛「晕」进来，不留硬边界。
- 地砖第一版太亮、对比太强，像矢量插画。必须压暗四周，只留下窗光照到的那块光池。

## v2 返修（审片：偏静 0.20 vs 0.46；主角被模糊、窗外反而清晰，景深倒置）
- 晕涂改为：模糊层 1.6px（原 2.6），清晰层 α0.82（原 0.38）。软边保留，五官和轮廓清楚了。
- 扑翼机放大 1.6 倍，航程 440→790，俯仰幅度 ±0.07；飞鸟增加到 14 只、放大 1–1.8 倍。
- 猫：头绕脖子歪蹭 ±0.16rad，眯眼松紧交替，尾巴 ×2.2，呼吸 ×3，look 左右转头。少女：发梢摆 ±11px，sip ×1.6。
- 窗外云影掠过河谷；光柱亮度随「云过日」以 0.75±0.35 变化；浮尘 70 颗。
- 静止段帧差：0.20（审片口径）／0.30（我量）→ 0.37。原片 0.43。
