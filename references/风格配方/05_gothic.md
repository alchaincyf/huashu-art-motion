# 05_gothic · 1290 哥特泥金手抄本

**中文** · [English](../en/style-recipes/05_gothic.md)

每帧 11–22ms（中位 12ms）。静态层＋金箔掩膜在 `init()` 里一次性建好。

## 管线
1. 静态层 `goth_static`（缓存）：羊皮纸 → 金箔 → 菱格压花 → 山墙、小尖塔、侧柱 → 尖拱窗和彩玻璃 → 桌子、宝座 → 拉丁文栏 → 页边小骑士。
2. 金箔掩膜 `goth_mask`：对静态层逐像素算「金色度」 `clamp((r-b-70)/50)·clamp((g-b-30)/40)·clamp((r-140)/40)`，结果当 alpha。羊皮纸 (236,223,194) 的 r−b 只有 42，被排除；粉色带 b 值高，也被排除。**不用再画一遍金色形状来做遮罩**，凡是金色的地方都会自动被高光扫到：背景、首字母、金球、山墙顶饰。
3. 每帧依次画：彩玻璃闪烁 → 斜向高光 → 高光经过处出现四角星 → 藤蔓花饰 → 蜗牛 → 跑过的老鼠 → 猫 → 少女 → 颗粒。

## 金箔质感（规范要求的「细纹理＋高光」）
- 逐像素着色：`f = 0.52 + fbm(x·.0035)·0.42 + 横向打磨纹 noise(x·.004, y·.09)·0.5 + 左上受光 + 颗粒±0.05`，再在 goldLo #9c6a1a / gold #d9a63a / goldHi #f8de86 三个色之间插值。打磨纹的 y 频率是 x 的 20 倍以上，所以看起来是横向的金属拉丝。
- 菱格：间距 46px，两族斜线（x+y、x−y 各为常数）。每条线画两遍：一遍暗线，一遍错开 1.2px 的亮线，看起来就是刻进金里的。菱心压 4 个点，左上亮、右下暗。
- 每隔 118×125px 画一条极淡的方块接缝，模仿一片片贴上去的金箔。
- 斜向高光：先在一张 920px 宽的 scratch 上画线性渐变带，斜率 K=0.45（“/” 方向）。用 `destination-in` 乘掩膜，再以 `lighter`、α0.62 叠回画面。**按匀速移动** `x = lerp(150,1650,(lt-0.08)/1.15)`。最初用 inOut 缓动，结果 0.9s 时高光已经扫出金区，少女身上看不到；改成匀速后，0.3s 扫到窗边，0.9s 正好扫过少女。光环、11 个固定点按 `|u − sweepX| < 70` 判定，在高光经过时出四角星闪光。

## 母题动画（0.25–1.4s 窗口内都看得出）
- 藤蔓：两条茎各约 120 个点，每个点加 `sin(t·2.1+i·.09)·2.5` 的摆动。每 3–5 个点挂一片三瓣常春藤叶（蓝/红/金轮换）或一颗带 3 根须的金球。叶片绕挂点按 `sin(t·3.1+k·1.7)·0.28` 摆。叶片缩放第一版用 0.85，太小太稀，改为 1.05–1.45 后，密度才接近原片。
- 彩玻璃：26 个随机点，`sin(t·5+h·40) > 0.6` 时点亮一团白色径向光。
- 猫抬起一只前爪，拎着老鼠尾巴，老鼠像钟摆一样摆 `0.32·sin(t·5.5)`，小腿乱蹬。蜗牛以 62px/s 向左爬，触角晃动；文字栏下的老鼠在 0.12–1.17s 内跑过 360px，腿每秒摆 40 弧度。
- 少女按共享编舞端起金杯，杯沿有一颗四角星闪烁，杯上热气用细墨线。

## 角色
- 少女直接拿 `RIG.girl` 的 Path2D 自己按顺序画，**不调 `RIG.drawGirl`**，原因有两个：drawGirl 一定会画成带把手的马克杯；斗篷和光环要插在中间某几层之间。画的顺序：光环（以 headC 为中心偏 (16,−22)，r=114，红圈加 36 颗压印点）→ 波浪长金发 → 红袍（金细竖条每 20px 一条，袍摆一道金边）→ 蓝斗篷（锚在 nape/back 上，带金边）→ 头 → 金圣杯。
- 猫做成手抄本里「人脸猫」：脸部是一块奶油色椭圆，杏眼瞳孔挤在右侧斜睨少女，上眼皮加粗，眉毛挑起，嘴角下撇，两颊红晕。只用 `legs[0]`，另一条前腿用 `RIG.limb` 自己画成抬起的姿势。
- 拉丁文正文用 UnifrakturMaguntia 44px。50px 会把 “cum poculo suo” 挤出画面右边。句首的 Cattus/Nemo/Mus 用朱红，这是中世纪的朱批做法。

## 坑
- scratchpad 和其它时代作者共用，`check.py` 被别人覆盖过一次。自检脚本要放进自己的子目录。
- 运动差分图如果拿 lt=0 当基准，会被引擎前 20 帧的镜头冲击（1.03 缩放）污染。基准要取 lt≥0.35。

## v2 微调
藤蔓摆幅 ×2、叶摆 0.42；彩窗闪点 40 个；金箔高光 α0.85、高光带加宽。静止段帧差 1.10 → 1.32（原片 1.64）。
