# 镜头表模板：先镜头表，再动手

轨道档的第 1 步。开阔档也建议先写一张，lint 可跑可不跑。

一张镜头表就是这支片子的分镜：每行一镜，写清楚这一镜画面里**有什么物、它在做什么、镜头怎么动、屏上有几个字、用什么做**。写得出这张表，片子就不会变成一页越堆越长的 PPT；写不出某一行，说明那一镜还没想清楚，先别写代码。

## 怎么写

复制下面这张空表到 `<项目>/镜头表.md`，一行一镜往下填：

```markdown
| 时间段 | 画面里的物 | 它在做什么 | 镜头 | 屏上字 | 做法 |
|---|---|---|---|---|---|
| 0–3 | （名词：一个人、一个东西） | （动词：它正在干什么） | 停／快推／横移／砸入／切 | （≤8 字，可空） | （y4 片段 镜01.json／scenes/xxx.js／素材 照片） |
```

| 列 | 写什么 | 不要写 |
|---|---|---|
| 时间段 | `0–3`、`3–7.5` 或 `0:03–0:07`，前一镜的结束就是后一镜的开始 | |
| 画面里的物 | 名词，画面上能指着说「就是它」的东西：一片面包、一粒孢子、主角的手 | 标题、要点、文字、列表、标签、字幕、卡片、背景、画面、图标；空镜、纯色、黑场、渐变底（主角不在画里） |
| 它在做什么 | 动词，这个物自己的动作：飘进来、裂开、钻进去、被切掉 | 出现、显示、展示、淡入、逐条出现 |
| 镜头 | 这一镜的主动作，五选一：停／快推／横移／砸入／切 | 匀速慢推 |
| 屏上字 | 每镜 ≤8 字，可以空；口播原文交给字幕 | 整句口播、三行要点 |
| 做法 | 用什么做：哪个语法的参数化片段（写 spec 文件名）、`scenes/<id>.js` 代码画、真实素材满幅 | |
| 标签（可选列） | 这一镜贴在物旁边的小标签，用顿号隔开 | 一镜超过 3 个；一排发光胶囊 |

五条要求，写完逐条对：

1. **开头 3 秒是一个具体的小场景，结尾也落在主角或主物的一个动作上**：开头是一个人或一个物在做一件和题目有关的事，不是标题，不是「今天我们来讲」；结尾是放进口袋、合上书、拉远看全貌这类动作，字可以写在画里的物上，不收在居中金句卡上。
2. **全片一个例子或一个角色贯穿**：同一片面包、同一个人、同一台机器从头走到尾，各镜讲的是它身上发生的事。
3. **一镜 2–6 秒**：个别镜可以到 8 秒。
4. **文字主导的镜头 ≤30%**：物列是标题/字、屏上字 7 个以上、或用 y5 动态文字做的，都算文字主导。
5. **相邻两镜不用同一版式**：这一镜是满幅特写，下一镜就换成横移、换成图表、换成另一个物。

做法列的两条硬线（轨道档第 3 步也写着）：**单个参数化片段最多撑 8 秒**（同一个 .json 在表里合计不超过 8 秒）；**一支片至少用 3 种不同的画面做法**（不同语法的片段、scenes 代码画、真实素材满幅，各算一种）。

## 检查

```sh
uv run <skill>/scripts/storyboard_lint.py <项目>/镜头表.md --script <项目>/文稿.txt   # 有口播稿就带上 --script
```

逐镜给红黄绿和改法，有红灯非零退出。红灯就改镜头表、重跑，**红灯没清不许开始写代码**。黄灯可以做，交付说明里逐条写理由。lint 查的是：物列不能空、不能只是版面词、不能是空镜/纯色/黑场这类空画面；做什么列要有动作；屏上字 ≤8；第一镜和最后一镜都不能是文字主导；文字主导 ≤30%；给了 `--script` 时屏上字里的数字（百分数、年份、带单位的数）要在文稿里找得到（文稿写「百分之六十」也认）；有「标签」列时一镜超过 3 个标签报黄；单镜 2–6 秒（6–8 秒黄、超过 8 秒红）；连续三镜同一个镜头动作报黄；做法列里同一个片段合计超过 8 秒、全片做法少于 3 种报红。「一个例子贯穿」和「相邻版式不同」机器查不了，自己对。

## 示例：为什么面包会发霉（54 秒，横屏）

这是写法示范：题材、物和镜头顺序不要搬进你的片子。贯穿全片的是同一袋吐司和它的主人小满。

| 时间段 | 画面里的物 | 它在做什么 | 镜头 | 屏上字 | 做法 |
|---|---|---|---|---|---|
| 0–3 | 小满和一袋吐司 | 小满撕开面包袋，手指停在一块青绿色斑点上 | 停 | | y4 片段 镜01.json |
| 3–6 | 那块绿斑 | 绿斑边缘一圈白毛，像地图一样往外扩 | 快推 | 三天前还没有 | 素材 霉面包照片满幅 |
| 6–10 | 一粒孢子 | 孢子从窗缝飘进来，翻着跟头落到面包上 | 横移 | 孢子 | scenes/spore.js |
| 10–14 | 那粒孢子 | 孢子壳裂开，伸出一根白丝扎进面包 | 快推 | | scenes/spore.js |
| 14–18 | 面包切面的气孔 | 白丝沿着气孔分叉，像树根一样往下钻 | 砸入 | 菌丝 | scenes/hyphae.js |
| 18–22 | 面包里的淀粉粒 | 菌丝尖端喷出酶，把淀粉粒剪成一颗颗糖 | 快推 | 淀粉→糖 | y1 片段 镜06.json |
| 22–26 | 厨房墙上的温湿度计 | 指针从 15°C 滑到 28°C，袋子内壁凝出水珠 | 切 | 28°C | scenes/kitchen.js |
| 26–31 | 两条霉斑面积曲线 | 台面那条一路往上冲，冰箱那条贴着底爬 | 快推 | 冰箱里慢得多 | t3 片段 镜08.json |
| 31–35 | 霉斑表面的小柱子 | 一根根小柱顶起黑色孢子球，孢子球砰地炸开 | 砸入 | | scenes/hyphae.js |
| 35–39 | 一团孢子云 | 孢子云飘过桌面，落向旁边那袋馒头 | 横移 | 下一站 | scenes/spore.js |
| 39–43 | 小满的手和面包刀 | 小满想把绿斑那一角切掉，剩下的接着吃 | 停 | 切掉就行？ | y4 片段 镜11.json |
| 43–47 | 被切开的面包剖面 | 透视一层层剥开，看不见的菌丝早已爬满半片 | 快推 | 看不见的部分 | scenes/hyphae.js |
| 47–51 | 小满和垃圾桶 | 小满把整袋吐司丢进去，扣上盖子 | 切 | | y4 片段 镜13.json |
| 51–54 | 小满和一袋新吐司 | 小满把新吐司塞进冷冻层，门一关，霜慢慢爬上袋子 | 砸入 | 冷、干、密封 | scenes/kitchen.js |

为什么这张表能过：开头是小满撕开袋子看见霉斑，不是标题；结尾回到小满手上，她把新吐司塞进冷冻层，三个字写在画里，不是一张金句卡；同一袋吐司从头到尾；14 镜里没有一镜是文字主导；每个 spec 只管一镜（最长 5 秒），scenes 可以跨镜复用；做法有 y4、素材、scenes、y1、t3 五种；镜头动作没有连续三镜相同。第 8 镜的曲线是示意，成片里要标「示意数据」。
