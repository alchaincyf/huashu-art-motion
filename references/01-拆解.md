# 01 · 拆解：拿到一段动画，一小时内拆到能写成代码

**中文** · [English](en/01-breakdown.md)

目标不是写观后感，是产出**能直接照着编程的规格**：每段的起止帧、转场机制和参数、镜内动作清单、计数器/字幕的数值曲线、构图坐标、音轨的网格与配器。文字是索引，数字和接触表才是正文。

第一次实战：2026-10-04 拆 X 上的 15 秒「Art History Speedrun」（16 个艺术时代、15 个转场），全流程约 1.5 小时（分镜 agent 79 分钟、音轨 agent 22 分钟，并行）。

## 一、先摸物理参数（5 分钟）

```sh
ffprobe -v error -show_entries format=duration:stream=codec_type,width,height,r_frame_rate,sample_rate -of default=nw=1 src.mp4
```
X 的视频从 syndication 接口拿最高档（`video_info.variants` 里挑最高码率），不要录屏。原片 60fps 就按 60fps 拆，帧号是之后所有规格的公共语言（秒 = 帧/60）。

## 二、全貌三张图（10 分钟）

1. **接触表**：4fps × 480 宽，30 帧一张，标时间戳。看一眼知道有几段、每段是什么。
2. **关键帧总览**：每段挑一张最干净的整帧拼成 4×5。后面所有工作的地图。
3. **频谱图**：`ffmpeg -lavfi showspectrumpic=s=1600x400:legend=1`。一眼看出音乐是否按段换配器、有没有坠落滑音、碎裂瞬态、拍点。谐波干净、16kHz 一刀切 = 代码合成＋AAC。

## 三、量出转场与节奏（15 分钟）

**逐帧灰度差**：缩到 192×108 灰度，相邻帧平均绝对差。静止段 <2，转场段 10–37。阈值 5 ＋ 去抖 12 帧，一次找全转场起点。存成 `diff.npy` 给所有 agent 共用。

找到起点后**拟合网格**：起点间隔如果是常数的整数倍，就有 BPM 网格（本片：起点 = 84 + 14.06·n 帧，残差 < 0.45 帧，= 128 BPM 八分音符）。网格一旦确认，画面和音乐的所有时间都写成「第几个八分音符」。

**每个转场一张 60fps 接触表**：从起点前 2 帧开始，每 2 帧取一张，取 0.5 秒，15 格。机制只能从这里看出来——「8 条竖条依次落下回弹」「20px 方块绕竖轴翻转、从猫的位置向外扩散」这种描述，粗看 4fps 图只会写成「方块转场」。

**参考帧取「转场开始前最后一帧」**，不是你觉得好看的那一帧。取早了会把上一段转场的余波（碎石块）当成画面内容（埃及第一版踩到）。

## 四、镜内运动：每段里到底什么在动（15 分钟）

运动热图：每段静止区间内逐像素取最大帧差，红色叠在灰度底图上，标出「运动面积占比」。

本片的结论推翻了第一印象：以为「每段就是一张画」，实际每段都有 2.5%–34% 的面积在动——岩画动物两张姿态交替奔跑、圣甲虫推太阳球、回纹带滚动、维苏威冒烟、金箔高光扫过、扑翼机飞过、四宫格换色……**没做这一步就开工，做出来就是「图片之间的转场」，会丢掉场景内部的连续运动。**

热图告诉你「哪里动」，再到 60fps 帧里看「怎么动」（周期、幅度、是两帧交替还是连续）。

## 五、分工给 agent 时的写法

- 分镜 agent 和音轨 agent 并行，各给一份完整说明：素材路径、已知事实（帧率、时长、粗看的段落表）、要的产物（分镜表.md / spec.json / 接触表目录 / 音轨拆解.md / 合成脚本）、方法要求（用数据证实，不凭想象）、回复格式（摘要＋最不确定的 3 处）。
- 让它们**先修正你的清单**。本片我把「1993→2026 的光圈转场」认成了一个「孟菲斯时代」，分镜 agent 第一条就纠正了。
- 全模态模型「听」音轨只当候选：乐器判断可信，BPM（报 120，实为 128）、动机音数、「每段一记嗖声」都是错的，必须用起音检测回校。

## 六、产物清单（拆完应该有）

| 产物 | 用途 |
|---|---|
| `分镜表.md` + `spec.json` | 每段起止帧、转场机制参数、镜内动作、计数器曲线、构图坐标 |
| `转场/T*.jpg`（60fps 接触表） | 写转场代码时逐帧对照 |
| `镜内运动/运动热图.jpg` | 每段动什么、动多大 |
| `结尾动作/`（如有角色表演） | 逐帧质心、轨迹、物理参数（重力 px/帧²） |
| `音轨拆解.md` + `synth.py`（模板：`scripts/audio/synth_艺术史速通.py`） | BPM 网格、每段八分音符数、动机、配器、音效序列 |
| `关键帧总览.jpg` + `生图/ref/*.png` | 构图地图、每段参考帧 |

脚本：`scripts/analyze/`（接触表、灰度差、转场接触表、运动热图），命令见各脚本 docstring。
