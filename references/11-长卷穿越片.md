# 11 · 长卷穿越片：一个人从左走到右，穿过一幅幅名画

**中文** · [English](en/11-long-scroll-films.md)

《花叔穿越名画》（2026-10-05，123.7 秒，24 个世界）用的做法。和艺术史速通（同一个房间换画风）不同，这里是**一条横向长画卷**：每个世界是一段横向延展的画，首尾相接；主角一直往右走，跨过边界那一刻，他的画风和世界一起换。

示范：`scripts/engine/demos/long_scroll/`，收了 3 段（埃及壁画 → 莫奈《日本桥》→ 8-bit 像素），约 15.6 秒。

```sh
uv run --with playwright python scripts/engine/render.py --film demos/long_scroll --stills 1,5,9 --out 试渲   # 三张静帧
uv run --with playwright python scripts/engine/render.py --film demos/long_scroll --out long_scroll.mp4       # 整段
```

浏览器预览：在 `scripts/engine/` 起一个静态服务，打开 `index.html?film=demos/long_scroll`；`&only=28_monet,14_8bit` 只排这几段，`&v=330` 试别的步速。

## 文件

| 文件 | 管什么 |
|---|---|
| `eras.js` | 片子入口：加载库、`FILM_ORDER`（段的顺序）、登记帧库、生成一个 `dur = WORLD.total` 的段 |
| `lib/world.js` | 骨架 `WORLD`：时间轴（走→停下互动→走）、主角行进、相机、按边界裁开的主角、边界、角标。**先读它的头部注释** |
| `lib/crossing.js` | `XING`：读帧库、画角色帧（`XING.actor`）、笔触材质、莫奈世界 |
| `lib/acts.js` | `ACT`：小剧本工具（打水漂的石子轨迹等） |
| `lib/xing2_*.js` | 几段共用的小工具，由段文件开头按需加载 |
| `segments/<id>.js` | 一个世界一个文件，调用 `WORLD.add({...})` |
| `frames/<key>/` | 角色帧库：8 张透明 PNG＋`meta.json`（每帧脚底锚点 `ax/ay`、尺寸、是否离地 `air`；`ref_h` 是站立身高的像素数） |

## 加一段

1. 在 `segments/` 新建 `<id>.js`，调用 `WORLD.add({ id, year, name, w, hero, acts, back, front, seam })`，接口见 `lib/world.js` 头部注释。世界本身用代码画，优先把 `scenes/<id>.js` 里现成的风格场景改造成横向延展的版本（段宽 2000–2800）。
2. 生角色帧：每个世界一张「走路 8 帧」，有互动的再加一张「互动 8 帧」，按该画风让生图模型重画、绿幕、切帧（`scripts/key_split.py`，做法见 10 号），放进 `frames/<key>/`，写好 `meta.json`。
3. 把 `<id>` 加进 `eras.js` 的 `FILM_ORDER`。
4. 渲静帧核边界两侧，再跑 `qa.py --project scripts/engine --film demos/long_scroll`，确定性必须 ✓。

## 关键约定（全片统一，写死在骨架里）

- **地面线 `WORLD.GROUND = 760`，主角站立身高 300，主角在画面 720px 处。** 段两端（x=0 和 x=w 附近 ±150px）地面必须回到 760，地平线尽量落在 480–560，跨边界时两边才接得上。中间可以有桥、台阶（`ground: lx => y`）。
- **所有事件相对「互动开始」定时。** 用 `WORLD.actT(段)` 拿到互动开始的全片时刻，`r = S.t - WORLD.actT(ME)`；不要写「进段后第几秒」。全片步速后来从 330 提到 560，按这条写的段一处都不用改。
- **镜头只进不退。** 相机目标 = 主角 x − 720 ＋ 互动时向前让出的 `lead`，取历史最大值再做高斯平滑，所以全程单调、停与起都不顿。互动想让镜头别动，就写 `lead: 0`。
- **每段的边界用该段的签名语言画**（`seam`：纸边、像素棋盘、彩块分栏线……），这是速通片「转场 = 下一个风格的签名语言」在长卷里的版本。
- **主角走路帧率随步速同比例**（`hero.fps`），8 帧一个步态循环；需要再过一层该画风的材质时，在段里写 `hero.draw(c, key, i, o, S)` 自己合成，不改共用库。
- **配乐**：画面先定，音乐后配。每段放整数拍，逐段把速度在 86–104 BPM 之间微调，让每条边界都落在小节第一拍（实测 24 条边界最大误差 11.7ms）；人耳听不出 ±8% 的逐段速度差。
- **不要替主角加没要的梗。** 骨架里有「帽子上摞纪念品」的功能（`FILM_HAT_ITEMS`），容易与场景争夺视觉注意力，默认关闭。

更多证据和数字见 `07-正面经验.md` 第 36–38 条。
