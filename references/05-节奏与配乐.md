# 05 · 节奏与配乐

**中文** · [English](en/05-rhythm-and-score.md)

拆解方法与可复用规律：`风格配方/_音轨_艺术史速通.md`（第 5 节「可复用规律」可以直接照抄）；合成脚本模板（原创示例乐谱）：`scripts/audio/synth_艺术史速通.py`。

## 要点

1. **先定 BPM 网格，画面和音乐都落在网格上。** 128 BPM、八分音符 0.234s 适合速通/蒙太奇。`eras.js` 的 `eighths` 就是每段占几个八分。
2. **加速靠每段变短，不靠提速。** 6 → 4×5 → 3×4 → 2×3 → 1×3 → 结尾放长。
3. **一个三音动机，每段换该风格的代表乐器、随和弦移调。** 和声一个四和弦循环就够。
4. **段间硬起音，不交叉淡化，不加嗖声。**
5. **结尾音效：停—悬—砸—反应—收**（叮 → 滑哨坠落 → 碎裂 → 猫叫 → 低音拨弦），时间点对齐画面事件帧。
6. **响度**：对齐参考片的积分 LUFS 与真峰；逐段比相对差值。
7. 全模态模型听音只当候选：乐器可信，BPM、动机音数、音效时间都要用起音检测回校。

## 和画面的对位

- 转场起点 = 网格点；镜头冲击（场景层 1.03 → 1.0，20 帧）落在同一点，听感上的「咔」和视觉上的顿挫是同一下。
- 结尾表演的动作帧（拍杯 3、杯子落地）对齐音频 onset，误差 3 帧以内。
- 没有参考片时：先写段落表（每段多少八分），再同时生成画面时间轴和配乐；之后改节奏只改 `eighths` 一处。
